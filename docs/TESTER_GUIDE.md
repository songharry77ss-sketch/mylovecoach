# 테스터 안내문

테스트를 도와줄 사람에게 그대로 복사해서 보내면 되는 글입니다.
링크가 바뀌면 이 파일도 같이 고쳐주세요.

---

## 아이폰 쓰는 사람에게

> 안녕하세요! 만들고 있는 앱 「나만의 연애코치」 테스트를 부탁드려요.
> 카톡 대화 캡처를 올리면 어떻게 답장하면 좋을지 알려주는 앱이에요.
>
> **설치 방법 (2분)**
> 1. 앱스토어에서 **TestFlight** 를 먼저 설치해주세요. 애플이 만든 공식 앱이에요.
> 2. 아이폰에서 아래 링크를 열고 **Accept → Install** 을 누르면 끝이에요.
>    https://testflight.apple.com/join/XXjaFEPm
>
> 가입이나 로그인은 없어요. 바로 대화 캡처 한 장 올려보시면 됩니다.
> 쓰다가 이상한 점 있으면 편하게 알려주세요!

**안 될 때**
- 링크를 눌렀는데 TestFlight 가 안 열린다 → 1번(TestFlight 설치)을 먼저 해야 합니다.
- "이 베타는 더 이상 테스터를 받지 않습니다" → 인원이 찼습니다. `node tools/asc-testflight.mjs --public-link 1000` 으로 늘리세요.

## 갤럭시·안드로이드 쓰는 사람에게

> 안녕하세요! 만들고 있는 앱 「나만의 연애코치」 테스트를 부탁드려요.
> 카톡 대화 캡처를 올리면 어떻게 답장하면 좋을지 알려주는 앱이에요.
>
> **설치 방법 (2분)**
> 1. 휴대폰 **크롬**에서 아래 주소를 열면 설치 파일이 내려받아져요.
>    https://github.com/songharry77ss-sketch/mylovecoach/releases/latest
> 2. 다 받아지면 알림을 눌러 실행해주세요.
> 3. "출처를 알 수 없는 앱" 경고가 뜨면 **설정 → 허용** 을 눌러주세요.
>    아직 스토어에 정식 출시 전이라 그런 거고, 한 번만 허용하면 됩니다.
>
> 가입이나 로그인은 없어요. 바로 대화 캡처 한 장 올려보시면 됩니다!

**안 될 때**
- 설치 파일이 안 열린다 → 삼성 인터넷 말고 **크롬**으로 열어보세요.
- 이미 설치돼 있는데 업데이트가 안 된다 → 기존 앱을 지우고 다시 설치해주세요.
  (서명이 같으면 덮어쓰기가 되지만, 플레이스토어판과 섞이면 충돌합니다)

## 설치 없이 그냥 써보고 싶은 사람에게

> 설치가 번거로우면 브라우저에서 바로 써도 돼요. 기능은 똑같아요.
> https://mylovecoach.vercel.app

## 배포 경로별 차이

| 경로 | 인앱결제 | 자동 업데이트 | 비고 |
|---|---|---|---|
| TestFlight (아이폰) | 동작 | 됨 | 빌드마다 베타 심사 필요(같은 버전이면 한 번만) |
| APK 직접 설치 (안드로이드) | **안 됨** | 안 됨 | 새 버전은 다시 받아야 함 |
| Play 내부 테스트 (안드로이드) | 동작 | 됨 | 테스터 이메일 등록 + 참여 수락 필요 |
| 웹 | 안 됨 | 항상 최신 | 설치 불필요 |

## 링크를 다시 만드는 방법

```bash
# 아이폰 공개 초대 링크 (켜기 / 끄기)
node tools/asc-testflight.mjs --public-link 500
node tools/asc-testflight.mjs --no-public-link

# 안드로이드 직접 설치용 APK (GitHub 릴리스에 올라감)
gh workflow run android-apk.yml

# 현재 상태 확인
node tools/play-status.mjs
node tools/asc-testflight.mjs
```
