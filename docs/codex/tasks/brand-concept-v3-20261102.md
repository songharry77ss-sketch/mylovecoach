# 작업: 브랜드·UI 시안 3차 — 「더 트렌디하고, 써 보고 싶게」 (2026-11-02)

## 왜 하는가

사장님: 「팀원들한테 공유하고 싶은데, 지금까지 나온 거 다 포함하고 **좀 더 트렌디하고 사용하고 싶게** 하는 거 3개 더 만들어 줘.」

- 1차(`docs/design/concept-20261102/`): 네온·골드·스포츠 HUD → 「짜친다」 (금속·네온·게임 HUD·의미 없는 영어 라벨·사람 없음·포스터 같음)
- 2차(`docs/design/concept-20261102-v2/`): 토스·틴더·범블·위피 결 (럽코·애프터·답장각) → 방향은 맞음
- **3차 목표**: 2차보다 한 단계 더 「요즘 앱」 같고, 20대가 보자마자 **「이거 깔아 볼래」** 하게. 원래 요청인 「남자도 좋아할 만큼 화려한데 깔끔하게」도 지킨다.

작업 시작 전에 2차 결과물 `docs/design/concept-20261102-v2/*/board.png`, `store-1.png` 를 열어 보고 품질 기준으로 삼는다(그대로 따라 하지 말고 더 낫게). 1차가 왜 짜쳤는지도 기억한다.

## 3차에서 「사용하고 싶게」 만드는 법

- **화면 하나에 할 일 하나**: 첫 화면에서 바로 「캡처 올리기」를 누르고 싶게. 결과는 스크롤 문서가 아니라 한 장씩 넘기는 카드·대화·스토리로
- **보상감**: 결과가 나올 때 숫자가 크게 터지고(「성공 확률 92%」), 캐릭터·사진·색이 반응한다. 공유하고 싶은 카드가 꼭 하나 있다
- **진짜 출시 앱 디테일**: 상태 표시줄·홈 인디케이터, 8pt 격자, 알약 버튼, 실제 같은 대화 내용, 정돈된 여백. 포스터·광고 같지 않게
- **새 기능 제안은 시안당 최대 1개**(예: 홈 화면 위젯, 연속 기록, 한 달 연애 결산). 화면에 넣었다면 README 의 「새 기능 제안」 항목에 반드시 적는다. 그 밖에는 아래 기능만 쓴다

## 앱이 실제로 하는 일 (없는 기능 금지)

- 카톡 캡처 한 장 → 상대 말투·호칭에 맞춘 **답장 3가지**(무난하게 / 센스 있게 / 직진), 각 답장에 「성공 확률 %」, 복사
- 캡처 없이 상황만 적어도 됨
- **속마음 분석**(가능성별 %: 관심 있음 62% / 바빠서 23% / 선 긋는 중 15%)
- **호감 온도**(25° → +10°), 상대 분석 보고서
- **KKTI**: 카톡 습관으로 보는 연애 유형 16가지(예: 「직진 불도저」), 친구와 궁합, 공유 카드
- **연애 연습**: AI 상대와 카톡 연습, 보낼 때마다 피드백 · **비밀 상담**
- 무료 횟수 → 하루 이용권 ₩2,700 / 평생 ₩29,800 · 탭: 홈 · 탐색 · 마이

1. `icon.png` 1024×1024 — 이미지 생성. 상징 하나 + 브랜드 색, 납작하고 또렷하게. 작게 줄여도 알아볼 것.
2. `store-1.png` 1290×2796 — 스토어 첫 장 겸 브랜드 무드컷(굵은 제목 두 줄 + 시안의 주인공 요소 + 앱 화면 일부).
3. 앱 화면 3장 1179×2556 (상태 표시줄·홈 인디케이터 포함):
   - `screen-1-home.png` 홈: 인사 + 「캡처 올리기」 큰 버튼 + 상황 적기 + 오늘 남은 무료 횟수 + 최근 상담(상대 이름·한 줄·호감 온도) + 아래 탭(홈·탐색·마이)
   - `screen-2-result.png` 코칭 결과: 상대 메시지 → 속마음 % → **답장 3가지**(성공 확률 크게, 복사) → 호감 온도. 시안 성격에 맞는 형식으로
   - `screen-3-*.png` 시안이 가장 빛나는 화면 하나(KKTI 공유 카드 / 연애 연습 / 결제 중 택1, 파일 이름에 무엇인지)
4. `board.png` 2400×1350 — 왼쪽: 로고타입 + 한 줄 슬로건 + 아이콘 + 색 견본(HEX)·글꼴, 오른쪽: store-1 과 화면 3장을 아이폰 목업으로 나란히. **팀원에게 공유하는 발표용 한 장**이라 가장 공들인다.
5. `README.md`(컨셉 한 단락, 이름 뜻, 색·글꼴·규칙, 레퍼런스에서 가져온 것, 「써 보고 싶게」 만드는 장치 3개, 새 기능 제안(있으면)) · `prompts.md`(이미지 생성 프롬프트)
