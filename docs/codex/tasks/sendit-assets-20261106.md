# 작업: 센딧(Sendit) 앱 안 3D 아이콘 자산 (2026-11-06)

## 왜 하는가

앱 이름이 **센딧(Sendit)** 으로 바뀌고(부제 「나만의 연애 코치」), 화면 전체를 새 로고 색으로 다시 만든다.
첨부 이미지가 새 앱 아이콘이다: 왼쪽 위 하늘색(#9EE6FF 근처)에서 파랑(#3D63F5)을 거쳐 오른쪽 아래 보라(#7A5CF8)로 흐르는 그라데이션 둥근 사각형, 가운데 흰 말풍선(꼬리는 왼쪽 아래), 말풍선 안에 파란 그라데이션 위쪽 화살표.
화면은 흰 바탕·연회색 카드·큰 한글(토스·「럽코」 시안 결)이고, 화면마다 **작은 3D 아이콘 하나**를 주인공처럼 둔다. 그 3D 아이콘 네 개를 만든다.

## 사장님 취향 (꼭 지킨다)

- 토스 결의 **말랑한 유광 플라스틱·클레이** 3D. 귀엽고 비싸 보이게, 「진짜 출시된 앱」처럼.
- 금지: 금속·크롬·유리 과잉·네온 빛 번짐·반짝이 장식·게임 HUD 느낌·영어 글자.
- 색은 아이콘과 같은 **하늘색 → 파랑 → 보라** 그라데이션 + 흰색. 분홍·빨강 계열 금지(하트도 흰색 또는 파랑-보라).

## 만들 것

폴더 `assets/images/sendit/` 에만 저장한다(다른 파일·앱 코드는 건드리지 않는다, git 커밋 금지).
모두 **1024×1024 PNG, 진짜 투명 배경(alpha)**, 물체 하나가 가운데 약 72%, 바깥 그림자·바닥·받침 없음, 글자 없음. 네 개가 한 세트로 보이게 같은 재질·같은 조명(왼쪽 위)·같은 각도(정면에서 살짝 기울임)로.

1. `bubble-send.png` — 아이콘을 3D 로 만든 것: 통통한 흰 말풍선(꼬리 왼쪽 아래) 앞면에 파랑-보라 그라데이션 위쪽 화살표가 살짝 볼록하게. 말풍선 뒤에 아이콘처럼 하늘색→보라 그라데이션의 둥근 사각 판을 둬도 좋다(판도 3D 클레이). 앱의 대표 마스코트 아이콘이다.
2. `bubble-heart.png` — 하늘색→파랑→보라 그라데이션 말풍선(꼬리 왼쪽 아래) 앞면에 흰 하트가 살짝 볼록하게. 「호감·답장」 화면용.
3. `bubble-memory.png` — 그라데이션 말풍선 두세 개가 살짝 겹쳐 쌓인 모양(뒤로 갈수록 작고 연하게) — 「센딧이 지난 대화를 기억해요」 화면용. 맨 앞 말풍선에 흰 점 세 개(…)를 볼록하게.
4. `ticket-time.png` — 그라데이션 입장권(양옆이 반달로 파인 티켓) 위에 흰 작은 시계(바늘 두 개)가 볼록하게 — 「하루 무제한 이용권·타임 세일」 카드용.

## 검수

PNG 를 직접 열어 보고: 바깥에 떨어진 점·얼룩·반투명 찌꺼기가 없는지, 가장자리가 매끈한지, 넷이 같은 세트로 보이는지, 분홍이 섞이지 않았는지 확인하고 고친다.
흰 바탕과 연한 회색(#F2F4F6) 바탕 위에서 모두 또렷해야 한다(흰 말풍선은 아주 옅은 파랑 그림자 면으로 형태를 살린다).

`assets/images/sendit/prompts.md` 에 생성·수정 프롬프트를 남긴다. 마지막 메시지는 파일 목록과 고친 점만 짧게.
