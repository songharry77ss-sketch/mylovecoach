# 작업: 앱 새 브랜드·UI 컨셉 시안 3종 (2026-11-02)

## 왜 하는가

사장님 요청: 「UI/UX 전반적으로 남자가 좋아할 만큼 화려한데 깔끔하게. 시안·컨셉이 필요하고, 앱 이름도 새로 추천. 시안 3개 정도.」

지금 앱(「나만의 연애코치」)은 로즈/라벤더 + 에스프레소·골드(`src/components/stage`) 톤이라 여성향·잔잔한 느낌이 강하다.
이번 시안의 목표는 **20~30대 남성이 열었을 때 「오, 멋있다」 하고 바로 써 보고 싶은 화면**이다.
- 화려함: 빛, 금속·유리 질감, 큰 숫자·게이지, 강한 대비, 게임·자동차·스포츠 앱 같은 긴장감
- 깔끔함: 한 화면에 핵심 하나, 넉넉한 여백, 정렬된 격자, 글자 크기 단계가 분명함. 장식이 정보를 가리면 안 된다
- 유치함·선정성 금지: 하트 남발, 핑크 범벅, 노출, 「픽업 아티스트」 같은 조작·공략 뉘앙스 금지. 「상대를 존중하면서 센스 있게」가 톤이다

## 앱이 실제로 하는 일 (화면에 넣을 기능 — 없는 기능을 만들지 않는다)

- **캡처 한 장 → 답장 추천 3가지**: 카톡 대화 캡처를 올리면 AI 가 상대 말투·호칭에 맞춘 답장 3개를 준다(예: 무난하게 / 센스 있게 / 직진). 각 답장에 「성공 확률 %」가 붙는다. 복사 버튼
- **상황만 적어도 됨**: 캡처 없이 「소개팅 후 애프터 어떻게 신청하지」처럼 적으면 조언·답장
- **속마음 분석**: 상대 속마음을 가능성별 % 막대로(예: 관심 있음 62% / 바빠서 23% / 선 긋는 중 15%)
- **호감 온도**: 대화할수록 오르는 온도 게이지(예: 25° → +10°)와 상대 분석 보고서
- **KKTI**: 카톡 습관으로 보는 연애 유형 16가지(예: 「직진 불도저」), 친구와 궁합·공유 카드
- **비밀 상담**, **연애 연습**(AI 상대와 카톡 연습, 보낼 때마다 피드백)
- 요금: 무료 횟수 → 하루 이용권 ₩2,700 / 평생 프리미엄 ₩29,800
- 탭: 홈(채팅) · 탐색 · 마이

실제 문구는 `src/app/(tabs)/index.tsx`, `src/app/quick.tsx`, `src/app/mind.tsx`, `src/app/kkti/`, `src/app/paywall.tsx` 를 읽고 참고한다(읽기만, 고치지 않는다).
지금 화면 캡처는 `docs/store-assets/ios-6.7/1~6-*.png` 에 있다(첨부 이미지와 같음) — **구조 참고용**이고, 색·스타일은 따라 하지 않는다.

## 만들 것 (시안 하나당)

1. **앱 아이콘** `icon.png` 1024×1024 — 이미지 생성 도구로. 글자 없이 상징 하나(새 앱 이름의 느낌). 작게 줄여도 알아보게. 프롬프트는 `prompts.md` 에 적는다.
2. **키 비주얼 소재** — 이미지 생성 도구로 화면 배경·질감·3D 오브젝트(예: 빛나는 말풍선, 금속 게이지, 네온 라인)를 2~5장. `_art/` 에 저장. 글자·로고 없음.
3. **앱 화면 3장** (HTML/CSS → PNG, 1179×2556, 아이폰 화면 비율, 상태 표시줄·홈 인디케이터 포함):
   - `screen-1-home.png` 홈: 인사 + 「캡처 올리기」 큰 버튼 + 상황 적기 입력칸 + 오늘 남은 무료 횟수 + 최근 상담 1~2개 + 아래 탭(홈·탐색·마이)
   - `screen-2-result.png` 코칭 결과: 상대 메시지 요약 → 속마음 % 막대 → **답장 3가지 카드(성공 확률 % 크게, 복사 버튼)** → 호감 온도
   - `screen-3-kkti.png` KKTI 결과 카드(게임 캐릭터 카드·트레이딩 카드처럼 화려하게: 유형 이름, 스탯 막대 4개, 궁합 좋은 유형, 공유 버튼) — 또는 결제 화면 중 시안에 더 잘 맞는 쪽 1장. 결제 화면을 고르면 하루 이용권 ₩2,700 / 평생 ₩29,800 두 개
   - 한국어 글자는 **HTML 로 정확하게**(이미지 생성 도구로 글자를 그리지 않는다). 글꼴은 Pretendard:
     `@font-face { font-family: P; font-weight: 700; src: url("file:///C:/Users/shsop/mylovecoach-concept-20261102/api/_assets/fonts/Pretendard-Bold.otf") }`
     `@font-face { font-family: P; font-weight: 500; src: url("file:///C:/Users/shsop/mylovecoach-concept-20261102/api/_assets/fonts/Pretendard-Medium.otf") }`
     (숫자·영문 제목에 시안 성격에 맞는 시스템 글꼴을 섞어도 됨: Segoe UI Variable, Bahnschrift, Georgia 등 윈도우 기본 글꼴만)
   - 질감: 여러 겹 그림자, 유리(backdrop-filter), 빛 번짐(radial-gradient), 금속 그라데이션, 미세한 노이즈. `_art/` 이미지를 배경·장식으로 쓴다.
   - 본문 글자 대비 4.5:1 이상, 최소 글자 26px(1179 폭 기준), 버튼 높이 120px 이상.
4. **보드** `board.png` 2400×1350 — 발표용 한 장: 왼쪽에 새 앱 이름 로고타입(HTML 글자) + 한 줄 컨셉 + 아이콘 + 색 견본 5개(HEX)와 글꼴 이름, 오른쪽에 화면 3장을 아이폰 목업(CSS 베젤·다이내믹 아일랜드)으로 나란히(가운데 것을 살짝 크게). 배경은 시안 분위기 그대로.
5. `README.md` — 컨셉 한 단락, 이름 뜻, 색(HEX)·글꼴·질감 규칙, 남성 사용자에게 먹힐 이유 3개, 지금 앱에서 바꿔야 할 컴포넌트 목록(짧게).
