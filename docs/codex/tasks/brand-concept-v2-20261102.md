# 작업: 브랜드·UI 시안 2차 — 틴더·범블·위피·토스 결로 (2026-11-02)

## 1차 평가와 이유

사장님: 「전반적으로 너무 짜쳐. 틴더, 범블, 위피, 토스 등을 참고해서 좀 더 트렌디하고 젊은 사람들이 느낌 있게 생각할 수 있게 다시.」

1차(`docs/design/concept-20261102/`)가 짜친 이유 — 이번에는 전부 하지 않는다:
- 금속·네온·유리 3D 오브젝트, 게임 HUD, 트레이딩 카드, 불도저 같은 장식이 많다. 「멋있어 보이려고 애쓴」 티가 난다
- 「YOUR NEXT MOVE」「COACHING, IN MOTION」 같은 의미 없는 영어 라벨
- 사람이 하나도 없다. 연애 앱인데 설렘이 없다
- 실제로 출시된 앱 화면 같지 않고 포스터 같다

## 레퍼런스에서 가져올 것 (첨부 이미지 4장: 토스·틴더·위피·범블 한국 App Store 스크린샷)

- **토스**: 흰 바탕, 넓은 여백, 아주 크고 굵은 한국어 문장과 숫자(「이자 1,200원이 쏙!」), 연회색 카드(#F2F4F6), 파란 버튼 하나, 화면마다 3D 아이콘 딱 하나, 친구처럼 말하는 문장(~해요)
- **틴더(한국)**: 20대 한국인의 자연스러운 일상 사진이 화면 가득, 사진 위에 이름·나이·말풍선 칩, 하트 버튼, 분홍·라일락 배경, 짧고 굵은 제목
- **위피**: 연보라·하늘 그라데이션 배경, 검정 굵은 제목에 핑크 강조, 흰 둥근 카드, 말풍선 대화, 3D 손 이모지
- **범블**: 한 가지 시그니처 색(노랑)으로 세계관을 통일, 흑백 인물 사진 + 색 글자, 「내 마음을 사로잡는 가장 빠른 방법은요」 같은 질문 카드, 노란 말풍선

공통 원칙: **실제 같은 젊은 사람 사진 + 브랜드 색 하나 + 흰 둥근 카드 + 말풍선 + 짧고 친근한 한국어.** 장식은 거의 없고, 화면이 곧 브랜드다.
다른 앱의 로고·색 조합 그대로·화면 배치를 베끼지 않는다. 분위기와 원칙만 가져온다.

## 앱이 실제로 하는 일 (1차와 같음 — 없는 기능 금지)

- 카톡 캡처 한 장 → 상대 말투·호칭에 맞춘 **답장 3가지**(무난하게 / 센스 있게 / 직진), 각 답장에 「성공 확률 %」, 복사
- 캡처 없이 상황만 적어도 됨
- **속마음 분석**(가능성별 %: 관심 있음 62% / 바빠서 23% / 선 긋는 중 15%)
- **호감 온도**(25° → +10°), 상대 분석 보고서
- **KKTI**: 카톡 습관으로 보는 연애 유형 16가지(예: 「직진 불도저」), 친구와 궁합, 공유 카드
- 무료 횟수 → 하루 이용권 ₩2,700 / 평생 ₩29,800 · 탭: 홈 · 탐색 · 마이
