# Codex 작업서 — 앱 화면 다국어 번역 (2026-11-27 세계 출시)

## 목적
연애 코치 앱의 세계판(영어 이름 **My Love Coach**) 화면 문장을 여러 언어로 번역한다.
앱은 영어 문장을 열쇠로 언어별 사전(`src/i18n/dict/<언어>.json`)을 찾아 바꾼다. 사전에 없는 문장은 영어로 나온다.

## 입력
- `src/i18n/source-en.json` — 번역할 영어 문장 배열 (약 2,080개). **읽기만 한다. 고치지 않는다.**
- 참고: `docs/I18N.md`(용어), `docs/STORE_LISTING_EN.md`(앱 소개). 앱 코드는 필요할 때만 맥락 확인용으로 읽는다.

## 출력
- 맡은 언어마다 `src/i18n/dict/<언어>.json` 하나: `{ "<영어 문장 그대로>": "<번역>" , ... }`
  - **원본의 모든 문장**을 열쇠로 넣는다 (빠뜨리지 않는다). 열쇠는 원본 문자열과 글자 하나까지 같아야 한다.
  - UTF-8, JSON 객체 하나. 2칸 들여쓰기 또는 한 줄 — 상관없음.
- 다른 파일은 만들거나 고치지 않는다 (임시 파일은 `tmp/codex-i18n/` 아래에만, 끝나면 지운다).

## 번역 규칙
1. 앱 이름 **My Love Coach** 와 상품·브랜드 이름(App Store, Google Play, Apple, Google, Kakao, Claude, GPT, Gemini, Anthropic, OpenAI, MBTI, KKTI)은 번역하지 않는다. 「Texting Type Test」는 그 언어로 자연스럽게 번역해도 된다.
2. 자리표 `{0}`, `{1}` … 는 **그대로 모두** 남긴다 (순서는 그 언어 어순에 맞게 바꿔도 된다). 이모지·기호(·, …, →, %)도 남긴다.
3. 20~30대가 쓰는 연애·데이트 앱(Tinder, Bumble, Hinge 수준)의 자연스럽고 짧은 말투. 직역하지 말 것. 버튼은 짧게.
   - 말투: 친근한 반말·캐주얼이 자연스러운 언어는 캐주얼(es tú, fr tu, de du, pt você, it tu …). 일본어는 です・ます를 기본으로 하되 딱딱하지 않게. 중국어·태국어 등은 앱에서 흔한 가볍고 친근한 말투.
   - 데이트 문화 말은 그 나라에서 실제로 쓰는 말로 (left on read · talking stage · double text · crush 등).
4. 법·결제 문장(구독 자동 갱신, 해지, 개인정보, 나이, AI 처리 동의)은 뜻을 정확히 옮긴다 — 줄이거나 바꾸지 않는다.
5. 원본이 문장 일부(`, regular {0}`, `· 1 use` 같은 조각)여도 그 조각만 자연스럽게 번역한다. 앞뒤 공백·문장부호 모양은 원본과 비슷하게.
6. 번역할 필요가 없는 것(예: `OK`, 이름, 코드처럼 보이는 것)은 그 언어에서 그대로 쓰는 게 자연스러우면 원문 그대로 둬도 된다.
7. 한글이 섞이면 안 된다. 외부 번역 API·인터넷을 쓰지 말고 직접 번역한다.

## 확인 (끝내기 전에 반드시)
`node tools/i18n/check-dicts.mjs <언어> [<언어> …]` — 빠진 문장, 자리표 불일치, 빈 번역, 한글 섞임, 영어 그대로 남은 비율을 본다. 실패가 0개가 될 때까지 고친다.
