# 결제 루프 (2026-11-17)

11/12 회의(10·11·12번)와 사장님 결정으로 무료 → 결제 → 재결제 흐름을 한 줄로 이었다.
정직하게 만든다: 실제 시각 기준 카운트다운, 취소선은 지금 판매 중인 정가, 거짓 희소성·되풀이 타이머 금지(표시광고법·전자상거래법 다크 패턴).

```
설치 ─ 첫 코칭 ──┬─ [A/B 실험군 50%] 5분 무제한 (안내 줄에 남은 시간) ─┐
                 └─ [대조군 50%] 지금 규칙                               ┤
                                                                         ▼
                                                     무료(맛보기·가입 보너스·매일 1회) 소진 → 막힘
                                                                         │
                 ┌─ 비회원(가입을 쓰는 빌드) ─ 결제 화면: 가입하면 무료 3회를 먼저 권함
                 └─ 회원 ─ ⏱ 타임어택 특가 팝업(/sale): 10분 특가 2,900원(정가 3,900원) → 팝업에서 바로 결제
                              └ 7일 쉬는 중·스토어에 특가 상품이 없음 → 일반 결제 화면
                                                                         ▼
                                결제 → 축하 → 막혔던 요청이 저절로 이어짐(use-resume-after-paywall)
                                                                         ▼
                 하루 이용권 끝나기 1시간 전: 채팅 안내 줄 「하루 무제한이 오후 3:42에 끝나요 · 1년권 보기」
                    → 결제 화면(renew): 1년권을 먼저 고르고 「1년권은 하루 이용권 8번 값보다 싸게 1년 내내」(스토어 가격으로 계산)
```

## 단계별

| 단계 | 어디 | 코드 |
| --- | --- | --- |
| 5분 무제한 (A/B) | 첫 코칭이 끝난 순간 시작, 채팅 입력창 위 「⏱ 처음 5분은 무제한이에요 · 04:12 남았어요」, 홈 남은 횟수 자리 | `INTRO_FREE_MS`·`introArm`(lib/billing/plans·store/app-store `consumeQuota`), 무료 상태 `intro`(lib/billing/quota) |
| 막혔을 때 경로 | 채팅·보고서·속마음·연습에서 무료가 없을 때 | `paywallTarget()`·`salePopupEligible()` (lib/billing/paywall-route) |
| 특가 팝업 | 아래에서 올라오는 시트, 큰 카운트다운, 팝업에서 바로 결제 | `src/app/sale.tsx` (데모 웹 미리보기 `/sale?preview=1`) |
| 결제 뒤 이어 하기 | 막혔던 코칭을 다시 누르지 않아도 보냄 | `hooks/use-resume-after-paywall.ts` (팝업도 닫힐 때 `paywallClosed()`) |
| 1년권으로 올리기 | 하루 이용권 1시간 전 안내 줄 → 결제 화면 `reason=renew` | `RENEW_NOTICE_MS`, paywall `renew` |

- 세일 규칙(10분, 7일에 한 번, 정가·특가 둘 다 스토어에 있을 때만)은 `docs/DAY_PASS_SALE.md`·`lib/billing/sale.ts` 그대로. 팝업이 뜨는 순간이 「조건에 맞는 결제 화면을 처음 볼 때」와 같은 시작점이다.
- 무제한(하루 이용권·구독·1년권·팀원·5분 체험 중)인 사람에게는 팝업·특가를 열지 않는다.

## A/B 실험 「처음 5분 무제한」

- **나누기:** 새로 설치한 기기를 50:50(`INTRO_FREE_SHARE`)으로 `introArm` 에 `on`/`off` 로 저장. 실험 전부터 코칭을 써 본 기기는 `na`(실험 밖).
- **실험군:** 첫 코칭은 대조군과 똑같이 1회 깎이고, 그 순간부터 5분 동안 깎지 않는다(기기당 한 번). 끝나면 지금 규칙 그대로.
- **기록:** 실험 안 기기의 모든 이용 기록에 `xp: 'free5:on' | 'free5:off'`(맨 앞 속성). 체험 시작 `intro_start`.
- **매일 보기:** 텔레그램 「📊 어제 리포트」 맨 아래 `🧪 A/B 처음 5분 무제한 (11/17부터 누적)` — 칸마다 앱을 연 기기 · 결제한 기기(비율) · 코칭 결과(기기당). (api/daily-report.ts)
- **판단:** 칸마다 기기 300대 이상 또는 2주가 지나면 결제 비율을 비교한다. 실험군 결제 비율이 대조군보다 뚜렷이 높고(기기당 코칭 증가로 늘어난 AI 비용을 매출이 넘으면) 실험군 규칙을 모두에게, 아니면 지금 규칙으로 되돌린다. 바꾸는 곳은 `INTRO_FREE_SHARE`(1 = 모두, 0 = 끔) 하나.
- 앱 안에서 세는 무료 규칙이라 새 규칙은 이 기능이 들어간 앱 버전부터 적용된다(서버는 남용 방지만).

## 이용 기록 (track)
