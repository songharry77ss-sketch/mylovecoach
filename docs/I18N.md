# 영어판 (세계 출시, 2026-11-27~)

기기 언어가 한국어면 지금 그대로, **그 밖의 모든 언어는 영어**로 나온다. 영어판 이름은 **My Love Coach** (한국어판은 그대로 「센딧」).
「Sendit」 은 해외 스토어에 같은 이름의 큰 앱(sendit - get it now, Iconic Hearts)이 있어 영어판에서는 쓰지 않는다.

## 다른 언어 (31개, 2026-11-27~)

- 기기 언어가 아래 중 하나면 그 언어, 아니면 영어: ja zh-Hans zh-Hant es pt fr de it ru tr id vi th ar hi pl nl sv da nb fi cs sk hu ro uk el he hr ms ca (`src/lib/i18n.ts` 의 LANGS).
- 코드는 그대로 `L(한국어, 영어)` — 영어 쪽을 열쇠로 `src/i18n/dict/<언어>.json` 에서 찾아 바꾼다 (`T()`·`deepT()`). 숫자가 든 문장은 `{0}` 틀로 맞춘다. 글자 부품 `AppText` 도 자식 글자를 한 번 더 번역한다.
- **영어 문장을 새로 쓰거나 고치면**: `node tools/i18n/extract-en.mjs` → 새 문장을 Codex 로 번역(`docs/codex/tasks/i18n-20261127.md`) → `node tools/i18n/check-dicts.mjs`. 사전에 없으면 영어로 나올 뿐 깨지지 않는다. `extract-en.mjs --check` 로 빠진 문장을 본다.
- 객체 안의 `id·code·gender·tone…` 같은 칸은 번역하지 않는다(i18n.ts 의 KEEP_FIELDS). 저장값 비교는 `T('Them')` 처럼 번역된 값도 함께 본다.
- AI: 요청 `lang` 이 언어 코드 — 서버가 설명은 그 언어, 답장은 대화 언어로 (`coach-schema.ts` 의 LANGUAGE_NAMES·systemFor). **새 언어 코드를 받는 서버를 앱보다 먼저 배포한다.**
- 아랍어·히브리어는 글자만 바뀌고 화면 배치는 그대로 (app.json expo-localization supportsRTL: false).
- 스토어 문구: `docs/store-listing/<언어>.json` (Codex, `tools/i18n/check-listings.mjs`).

## 쓰는 법

```ts
import { L, isKo, isEn } from '@/lib/i18n';

<Text>{L('답장 추천받기', 'Get reply ideas')}</Text>
const title = L(`${n}개 남았어요`, `${n} left`);
const img = L(require('…/step-1.png'), require('…/step-1-en.png'));
{isKo && <SpeechLevelPicker />}   // 한국어에만 있는 기능(존댓말 등)은 영어판에서 숨긴다
```

- 문구 키·번역 파일을 따로 두지 않는다. 한국어 문구 바로 옆에 영어를 적는다 → 파일마다 따로 작업해도 겹치지 않는다.
- 언어는 앱을 켤 때 한 번 정해지므로 모듈 맨 위 상수(`const TIPS = [...]`)에서 `L()` 을 써도 된다.
- 웹(mylovecoach.vercel.app)은 한국어 홍보 화면이라 `?lang=en` 일 때만 영어 (스크린샷 찍을 때 씀).
- 테스트(jest)는 한국어. 영어는 `APP_LANG=en npx jest …` 로 확인.

## 서버가 같이 쓰는 파일 — `L()` 금지

`api/` 가 불러 쓰는 파일은 `@/lib/i18n`(expo-localization, 앱 전용)을 불러오면 서버가 깨진다:
`src/lib/coach-schema.ts` · `ai-tasks.ts` · `ai-schemas.ts` · `gemini.ts` · `kkti.ts` · `billing/plans.ts` · `version.ts` · `release-notes.ts` · `ai-report-schema.ts` · `ai-backup.ts` · `knowledge/*` · `types.ts` · `src/constants/brand.ts`

이런 파일의 화면 문구는 ① 영어 값을 옆에 따로 내보내고(`TITLE_KO`/`TITLE_EN` 또는 `{ ko, en }`) 화면 쪽에서 `L()` 로 고르거나 ② 앱 전용 짝 파일(예: `kkti-en.ts`)을 만들어 화면에서만 불러온다. AI 프롬프트는 한국어 그대로 두고 요청의 `lang` 으로 서버가 영어 출력을 지시한다.

## 번역 원칙

- 미국 20대가 쓰는 자연스럽고 짧은 영어. 직역하지 말고 같은 뜻의 앱 문구로. 버튼은 2~3단어.
- 한국 문화 말은 바꾼다: 카톡/카카오톡 → texts·chats (메신저 이름이 필요하면 iMessage·WhatsApp·Instagram DM), 썸 → talking stage, 썸남/썸녀 → your crush, 읽씹 → left on read, 안읽씹 → left on delivered, 소개팅 → blind date, 밀당 → playing hard to get, 고백 → asking them out, 호감 → interest.
- 존댓말·반말 같이 영어에 없는 선택지는 영어판에서 숨기거나(`isKo &&`) 영어에 맞는 말(casual/polite)로.
- 가격은 화면에 박지 않는다 — 스토어가 준 현지 가격(`localizedPrice` 등)을 쓴다. 한국어판에 박힌 `₩3,900` 같은 대체 문구는 영어판에서 빈칸이나 「See price」로.
- 날짜·시간: 영어는 `Nov 27`, `9:41 PM`, `3 min ago`.
- 법·약관 링크: 영어판은 `/en/terms`, `/en/privacy` (사이트에 영어 문서를 둔다).
- 「고려대학교 심리학 연구진이 개발한」 → "Developed with psychology researchers at Korea University".
- AI 라는 사실(「AI 답변」, 신고 버튼 등)은 영어판에도 똑같이 보인다 (스토어 정책).
