# 앱스토어 「앱이 수집하는 개인정보」 설문 답안

앱스토어 심사 제출에 꼭 필요한데 **API 가 없어서 화면에서만** 할 수 있는 단계입니다.
아래대로 고르고 **게시**까지 누르면, 15분 안에 `app-store-autosubmit.yml` 이 알아서 심사에 제출합니다.

컴퓨터 브라우저가 편합니다. 휴대폰이면 사파리/크롬에서 「데스크톱 웹사이트 요청」을 켜세요.
(App Store Connect 앱에서는 이 설문을 고칠 수 없습니다)

처음 두 표는 **App Store의 8개 유형** 기준입니다. **Play 데이터 보안의 현재 9개 유형과 작업 상태**는 아래 「2026-10-08 Play 데이터 보안」 절을 따릅니다.

## 순서

1. https://appstoreconnect.apple.com 로그인 → **앱** → **나만의 연애코치**
2. 왼쪽 메뉴 **앱 개인정보 보호** (App Privacy) → **시작하기** (Get Started)
3. "이 앱에서 데이터를 수집합니까?" → **예, 이 앱에서 데이터를 수집합니다**
4. 아래 **8가지**에 체크하고 저장

| 분류 | 체크할 항목 |
|---|---|
| 연락처 정보 (Contact Info) | 이름 (Name) |
| 사용자 콘텐츠 (User Content) | 사진 또는 비디오 (Photos or Videos) |
| 사용자 콘텐츠 (User Content) | 기타 사용자 콘텐츠 (Other User Content) |
| 식별자 (Identifiers) | 기기 ID (Device ID) |
| 구입 항목 (Purchases) | 구입 내역 (Purchase History) |
| 사용 데이터 (Usage Data) | 제품 상호 작용 (Product Interaction) |
| 진단 (Diagnostics) | 기타 진단 데이터 (Other Diagnostic Data) |
| 기타 데이터 (Other Data) | 기타 데이터 유형 (Other Data Types) |

5. 항목마다 **설정** 을 눌러 아래처럼 답합니다

| 항목 | 용도 | 사용자 신원에 연결? | 추적에 사용? |
|---|---|---|---|
| 이름 | 앱 기능, 분석 | 예 | 아니요 |
| 사진 또는 비디오 | 앱 기능 | **아니요** | 아니요 |
| 기타 사용자 콘텐츠 | 앱 기능, 분석 | 예 | 아니요 |
| 기기 ID | 분석 | 예 | 아니요 |
| 구입 내역 | 분석 | 예 | 아니요 |
| 제품 상호 작용 | 분석 | 예 | 아니요 |
| 기타 진단 데이터 | 앱 기능, 분석 | 예 | 아니요 |
| 기타 데이터 유형 | 앱 기능, 분석 | 예 | 아니요 |

   용도에서 **앱 기능 (App Functionality)**, **분석 (Analytics)** 외에는 아무것도 고르지 않습니다.
   추적(Tracking)은 전부 **아니요** 입니다 — 광고 SDK 도, 데이터 판매도 없습니다.

6. 오른쪽 위 **게시** (Publish) — 이걸 눌러야 끝납니다. 저장만 하면 심사 제출이 계속 막힙니다.

## 왜 이렇게 답하나 (코드 근거)

| 항목 | 실제로 보내는 것 | 근거 |
|---|---|---|
| 이름 | 온보딩에서 적은 내 이름(별명). 코칭 요청마다 서버를 거쳐 Gemini 로 가고, 이용 기록에 동의하면 `app_user.name` 에 저장 | `CoachRequestSchema.user`, `supabase/schema.sql` |
| 사진 또는 비디오 | 대화 캡처. Gemini 가 분석만 하고 **우리 서버엔 저장하지 않음** (첨부 여부만 기록) → 신원 연결 안 됨 | `api/coach.ts` 의 `has_image` |
| 기타 사용자 콘텐츠 | 상황 설명 글, 상대 이름, 받은 답장. 동의하면 `coach_log` 에 기기 ID 와 함께 저장 | `coach_log` 테이블 |
| 기기 ID | 앱이 만든 무작위 ID (광고 ID 아님). 이용 기록 동의 시에만 전송 | `src/lib/analytics.ts` |
| 구입 내역 | 이용 중인 프리미엄 종류(주간·평생). 이용 기록 동의 시에만 전송. 결제 자체는 스토어가 처리 | `app_user.premium_plan` |
| 기타 진단 데이터 | 코칭 요청의 응답 시간·오류 메시지. 동의 시에만 저장 | `coach_log.latency_ms`, `error` |
| 제품 상호 작용 | 화면별 체류 시간, 버튼·이벤트. 동의 시에만 | `screen_view`, `app_event` |
| 기타 데이터 유형 | 나와 상대의 성별·나이·MBTI. 코칭 요청에 쓰이고 동의하면 저장 | `CoachRequestSchema`, `app_user` |

이용 기록은 사용자가 고르는 **선택 동의**이지만, 애플 기준에서 「드물게·일회성으로 수집」하는 예외에는 해당하지 않으므로 신고해야 합니다.

## 2026-10-08 Play 데이터 보안 — 초안 저장 완료, 검토 미전송

아래는 코드·제공사 정책 검토를 반영해 **2026-10-08 Play 콘솔에 저장한 9개 유형 답안**입니다. 화면의 「변경사항이 저장되었습니다. 게시 개요에서 전송하여 검토를 받으세요」 안내를 확인했습니다. **검토를 위해 전송하지 않았으며**, 최종 검토 전송은 사용자 확인 뒤 별도로 진행합니다.

모두 **수집함 · 공유 안 함 · 임시 처리 아님**입니다. 「공유 안 함」은 아래에서 확인한 서비스 제공업체 처리와 데이터셋 공유 상태에 근거합니다.

| Play 분류 | 데이터 유형 | 필수/선택 | 목적 | 실제 수집 근거 |
|---|---|---|---|---|
| 개인 정보 | 이름 | 선택 | 앱 기능·애널리틱스 | 선택 입력한 이름·별명, 동의한 프로필 기록 |
| 개인 정보 | 기타 정보 | 선택 | 앱 기능·애널리틱스 | 선택 입력한 성별·나이·MBTI 등 |
| 금융 정보 | 구매 내역 | 선택 | 애널리틱스 | 이용 기록 동의 시 프리미엄 종류·구매 이벤트; 카드 정보는 수집하지 않음 |
| 메시지 | 기타 인앱 메시지 | **필수** | 앱 기능·애널리틱스 | AI 코칭 입력·대화 분석·연습 채팅, 이용 기록 동의 시 코칭 질문·답 기록 |
| 사진 및 동영상 | 사진 | 선택 | 앱 기능 | 선택한 대화 캡처를 Gemini로 전송; 글 입력으로 대체 가능 |
| 앱 활동 | 기타 사용자 제작 콘텐츠 | **선택** | 앱 기능·애널리틱스 | 메시지 외의 선택 메모·프로필 추가 내용·AI 답변 신고 |
| 앱 활동 | 앱 상호작용 | 선택 | 애널리틱스 | 이용 기록 동의 시 화면·버튼·이벤트 기록 |
| 앱 정보 및 성능 | 진단 | 선택 | 앱 기능·애널리틱스 | 동의한 응답 시간·오류 기록, 선택 신고의 앱 버전·플랫폼 정보 |
| 기기 또는 기타 ID | 기기 또는 기타 ID | **필수** | 앱 기능·애널리틱스·사기 예방, 보안, 규정 준수 | 호출 제한용 IP 해시; 이용 기록 동의 시 무작위 기기 ID; 선택한 팀원 확인·서버 기록 삭제 요청의 기기 ID |

- 메시지를 「기타 사용자 제작 콘텐츠」와 분리했습니다. AI 대화에 필요한 메시지는 필수이고, 그 밖의 메모·신고 등은 선택입니다. 메시지가 필수여도 **이용 기록 수집은 계속 선택 동의**이며, 동의 없이 코칭 기록을 데이터베이스에 저장하지 않습니다.
- 기기 ID의 필수 판단은 팀원 기능이 아니라 **호출 제한에 쓰는 IP 해시**를 포함한 결과입니다. `api/_limits.ts`는 요청 사이에 해시와 호출 시각을 메모리에 보관하므로 요청 한 번에만 쓰고 폐기하는 임시 처리로 보지 않습니다. 앱에서 만든 무작위 기기 ID의 분석 전송은 계속 선택입니다. IP를 위치로 변환하는 코드는 없으므로 이 판단으로 위치 수집을 추가하지 않습니다.
- 전송 구간 암호화 **예**, 데이터 삭제 요청 **예** — https://mylovecoach.vercel.app/delete-data.html . 현재 배포 앱에는 계정 생성이 없습니다. 회원가입이 배포될 때 OAuth·계정 삭제 답안을 별도로 갱신합니다.

## 2026-10-08 Gemini 유료 서비스 확인 및 보관 안내 정정

운영 Gemini API 프로젝트가 활성 결제 계정에 연결된 **유료 서비스**임을 AI Studio 결제 화면에서 확인했습니다. [Gemini API 유료 서비스 약관](https://ai.google.dev/gemini-api/terms)에 따라 Google은 프롬프트(시스템 지침·캐시 내용·이미지 등 파일 포함)와 생성된 응답을 자사 제품 개선에 사용하지 않고 데이터 처리 부속약정에 따라 처리합니다. 개인정보 처리방침 2번과 10번도 이에 맞췄습니다. 결제 등급 확인이 데이터 보관 없음이나 Play 콘솔 반영 완료를 뜻하지는 않습니다.

사진을 우리 서버에 저장하지 않는다는 사실만으로 Play의 「임시 처리」에 해당하지는 않습니다. [Play 기준](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)은 해당 요청을 실시간으로 처리하는 동안 메모리에만 보관하는 경우입니다. Google은 유료 서비스에서도 Gemini API의 텍스트 입력·추가 맥락·출력을 안전 및 금지된 사용 방지 등의 목적으로 [55일 보관한다고 안내](https://ai.google.dev/gemini-api/docs/usage-policies)합니다. 이 앱에 적용되는 별도의 보관 예외를 확인하지 않았으므로 사진 입력이 요청 직후 모두 삭제된다고 가정하지 않습니다. 이는 **원본 사진 파일을 반드시 55일 보관한다는 단정이 아닙니다**. 사진 첨부는 글 입력으로 대신할 수 있어 선택 수집입니다.

AI Studio의 로그·데이터셋 공유 설정은 결제 등급과 별도로 확인했습니다. 2026-10-08 운영 프로젝트 화면에서 **GenerateContent API 저장 꺼짐, 로그 0개, 기존 데이터셋 없음**을 읽기 전용으로 확인했으며 설정은 바꾸지 않았습니다. Interactions API 저장은 기본값인 켜짐이지만, 현재 앱은 GenerateContent API를 사용합니다. 이 확인은 위의 남용 방지용 보관이 없다는 뜻이 아닙니다. Google에 데이터셋을 자발적으로 공유하면 해당 데이터에는 제품 개선·모델 학습을 허용하는 [별도 공유 규칙](https://ai.google.dev/gemini-api/docs/logs-policy)이 적용됩니다. Play의 「공유 없음」은 개발자 지시에 따라 처리하는 [서비스 제공업체 예외](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)를 근거로 판단했으며, 위 10월 8일 콘솔 저장 답안에 반영했습니다.

| 연애 연습 · 속마음 풀이 | 연습 대화·상황 글 → 중계 서버 → Gemini | 위와 같음. 이용 기록에도 남기지 않음 |
| 비밀 상담 | 코칭 요청은 보내지만 기기 ID 헤더를 빼서 서버가 기록하지 않음, 기기에도 저장 안 함 | 수집 줄어듦 |
| 하루 이용권 · 횟수권 | 결제는 스토어가 처리, 잔여·거래 ID 는 기기에만 | 「구입 내역」 항목 그대로 |
| 플로팅 버블(Android) | 화면 내용을 읽지 않음. 바로가기 버블만 띄움 | 수집 없음 |
| AI 분석 동의 시트 (지침 5.1.2(i)) | 없음. 처음 AI 를 쓸 때 무엇을 어디로 보내는지(중계는 Google(Gemini), 개인 키면 그 키의 회사 · 국외 이전) 알리고 동의를 받는다. 동의 여부·시각·안내한 회사는 기기에만 저장 (`src/store/app-store.ts` 의 `aiConsent`·`aiConsentProvider`·`aiConsentAt`). 이용 기록에 동의했으면 `ai_consent`(agreed·provider·via)와 `ai_consent_withdraw` 이벤트만 | 수집 늘지 않음. 동의 전·거절 시 AI 로 아무것도 보내지 않음 |
| 이용 기록 동의 다시 받기 | 첫 화면 체크박스 기본값을 꺼짐으로. 예전에 미리 체크된 채로 저장된 동의(`analyticsConsentVersion` 없음)는 「아직 묻지 않음」으로 읽어, 마이 탭에서 다시 켜야 수집. 그 동의로 이미 보낸 서버 기록은 지우지 않되(팀 결정), 그 기기에 `legacyServerRecords` 를 표시해 마이 탭 「예전에 보낸 이용 기록 지우기」로 지울 수 있게 함. 「모든 데이터 삭제」는 이용 기록·AI 분석 동의를 처음 상태로 돌림 | 수집 줄어듦 |

## AI 답변 신고 (플레이 생성형 AI 정책)

신고 시트에서 「신고하기」를 누르면 `api/report.ts` 가 Supabase `ai_report` 표에 저장하고 1년 뒤 지운다. 이용 기록 동의와 관계없이 보내고, 기기 ID·IP 는 저장하지 않는다(처리방침 2번 「AI 답변 신고」).

| 보내는 것 | App Store 유형 | Play 데이터 보안 유형 |
|---|---|---|
| 신고한 AI 답변(화면에 보이는 그대로 — 상대 이름 등 대화 일부가 들어갈 수 있음, 속마음 풀이는 물어본 상황 글 포함), 고른 사유, 직접 적은 메모 | 사용자 콘텐츠 → 기타 사용자 콘텐츠 | 앱 활동 → 기타 사용자 제작 콘텐츠 (대화 내용은 메시지 → 기타 인앱 메시지에도 해당) |
| 기능 종류, 답변을 만든 AI, 앱 버전, 기기 종류(iOS·Android·웹) | 진단 → 기타 진단 데이터 | 앱 정보 및 성능 → 진단 |

- **App Store**: 애플의 「선택 공개」 예외는 넷째 조건(제출 양식에 이용자 이름이나 계정명이 눈에 띄게 보일 것)을 채우지 못한다 — 신고 시트는 익명이다. 그래서 신고해야 하는 수집이다. 다만 「기타 사용자 콘텐츠」(앱 기능·분석)와 「기타 진단 데이터」가 이미 게시돼 있고, 목적(부적절한 답변 검토)은 앱 기능 안이라 **답 변경 없음**. 신고 행만 보면 신원에 연결되지 않지만, 같은 유형인 코칭 기록(`coach_log`)이 기기 ID 와 함께 저장되므로 유형의 「신원에 연결」 답은 「예」 그대로.
- **Play 데이터 보안**: 신고는 이용자가 고르는 선택 수집이며, 위 10월 8일 답안의 「기타 사용자 제작 콘텐츠 · 수집 · 임시 처리 아님 · 선택 · 앱 기능+애널리틱스」에 포함한다. 신고 내용에 실제 대화가 포함되면 「기타 인앱 메시지」에도 해당하며, 해당 유형은 AI 대화 기능 때문에 필수로 신고한다. 보관 1년. Vercel·Supabase 는 서비스 제공업체라 공유가 아니고, 신고는 Gemini 로 보내지 않는다.
- **기기 ID 는 신고 본문·저장 행에 없다.** 이용 기록 동의가 꺼져 있어도 앱의 무작위 기기 ID를 보내는 곳은 `/api/team`(「내 기기 ID」에서 팀원 등록을 요청한 기기(14일 동안)와 등록된 팀원만, `src/lib/billing/team.ts`의 `refreshTeam`)과 서버 기록 삭제 요청(`DELETE /api/track`, `src/lib/server-deletion.ts`)이다. 이 선택 기능과 별도로 호출 제한용 IP 해시가 쓰이므로, Play의 「기기 또는 기타 ID」는 위 표처럼 필수·보안 목적을 포함해 신고한다.
