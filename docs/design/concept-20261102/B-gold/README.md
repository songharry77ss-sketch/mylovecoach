# 한 수 · HANSU

**B-gold / 블랙 카드 — 연애의 한 수**

무광 검정 카드 위에 샴페인 골드의 빛과 브러시드 메탈의 결을 얹은 연애 코칭 앱 시안입니다. 고급 시계의 정밀한 눈금과 메탈 카드의 단정한 테두리에서 조형 원리를 가져오되, 넓은 여백과 큰 세리프 숫자로 정보를 먼저 읽게 합니다. 캡처 한 장에서 얻은 세 가지 답장을 **1수·2수·3수**로 보여 주며, 상대의 말투와 속도를 존중하는 선택을 돕습니다.

## 이름과 심벌

**한 수**는 대화가 막히는 순간에 건네는 결정적인 한마디입니다. 상대를 이기는 기술보다, 진심을 더 잘 전하는 다음 선택을 뜻합니다. 영문 표기는 **HANSU**, 슬로건은 **연애의 한 수**입니다.

아이콘은 대각선 홈 하나를 새긴 독자적인 금속 대화 토큰입니다. 문자 없이 하나의 실루엣으로 작은 크기에서도 구분되도록 했습니다. KKTI에는 전진하는 형태의 정밀 금속 조형물을 사용해 추진력을 표현합니다. 생성 이미지 안에는 문구나 로고를 넣지 않고, 화면의 한국어는 HTML 텍스트로 구성합니다.

## 색과 글꼴

| 역할 | 색상 | 사용 규칙 |
| --- | --- | --- |
| 옵시디언 | `#0B0C0E` | 화면과 보드의 기본 배경 |
| 차콜 | `#17191D` | 카드와 입력 영역의 표면 |
| 샴페인 | `#D6BC88` | 주요 버튼, 선택 상태, 핵심 수치와 금속 테두리 |
| 아이보리 | `#F3EBDD` | 제목과 본문 |
| 웜 그레이 | `#A5A39E` | 보조 설명과 메타 정보 |

- 한국어는 **Pretendard Medium 500 / Bold 700**, 주요 숫자는 **Georgia**, 영문 보조 표기는 **Segoe UI**를 사용합니다.
- 1179px 화면 기준 글자 최소 26px, 버튼 높이 최소 120px를 기준으로 설계합니다. 본문은 어두운 표면에서 명암 대비 4.5:1 이상을 유지합니다.
- 금속 질감은 얇은 그라데이션 테두리와 미세한 결로 표현합니다. 여러 겹 그림자, 낮은 강도의 유리 효과, 가장자리의 방사형 빛을 겹치되 글자 뒤의 광량은 억제합니다.
- 생성 소재는 장식과 분위기에 사용합니다. 성공 확률·속마음·호감 온도 등의 정보는 정확하게 정렬된 HTML 요소로 표현합니다.
- 골드는 핵심 행동과 읽어야 할 숫자에 집중합니다. 카드마다 장식을 늘리기보다 여백과 반복되는 정렬로 일관성을 만듭니다.

## 사용자에게 매력적인 이유

20~30대 남성이라는 목표 집단 안에서도 취향은 다양하다는 전제로 다음 세 가지를 제안합니다.

1. **소장하고 싶은 도구의 인상.** 정밀 금속과 차분한 검정은 시계·오디오·자동차의 재료감을 좋아하는 사용자에게 익숙한 완성도를 전달합니다.
2. **빠르게 비교할 수 있는 결과.** 큰 확률 숫자와 1수·2수·3수 구조는 긴 설명을 읽기 전에 답장의 차이를 파악하고 복사할 수 있게 합니다.
3. **공유할 만한 자기 표현.** KKTI를 정교한 유형 카드로 보여 주어 자신의 대화 습관을 살펴보고 친구와 공유하는 재미를 줍니다. 공격적이거나 상대를 조종하는 표현은 사용하지 않습니다.

## 화면과 데이터

- **홈:** 인사, 캡처 올리기, 상황 입력, 오늘 남은 무료 횟수, 최근 상담, 홈·탐색·마이 탭.
- **코칭 결과:** 상대 메시지 요약, 속마음 가능성 막대, 성공 확률과 복사 버튼을 갖춘 답장 세 카드, 호감 온도.
- **KKTI:** 기존 유형 **직진 불도저 / 선빠폭직**. 연락 시작·답장 속도·표현·진도 네 축을 각각 **92%·83%·100%·92%**로 표시하는 예시입니다. 궁합 좋은 유형은 기존 데이터의 **꼬리 흔드는 골댕이 / 후빠폭직**입니다.

화면의 인물명, 메시지, 확률, 온도, 잔여 횟수와 KKTI 수치는 시각화를 위한 예시 데이터입니다. KKTI 수치는 유형별 고정 능력치가 아니라 실제 앱처럼 테스트 응답에 따라 달라지는 성향 값입니다. 새로운 서비스 기능을 구현한 결과물이 아니며, 앱 코드와 기존 이미지에는 변경을 가하지 않습니다.

## 시각 검수

아이콘, 세 화면, 보드 PNG를 직접 열어 한글 렌더링·겹침·잘림·이미지 로딩을 확인했습니다. 보드 초안에서 왼쪽 하단의 콘셉트 설명과 푸터가 겹쳐, 브랜드 영역부터 색 견본까지 세로 간격을 줄였습니다. 코칭 결과에서는 가장 높은 속마음 가능성의 라벨과 수치를 골드로 통일했습니다. 두 파일을 다시 렌더한 뒤 직접 열어 수정 결과를 확인했습니다.

`inspect.mjs` 검사에서 모든 Pretendard 폰트와 이미지가 정상 로드됐고, 최소 글자는 26px, 버튼 높이는 120px 이상, 화면 밖으로 나간 텍스트는 0개였습니다. 아이콘 1024×1024, 화면 3장 각 1179×2556, 보드 2400×1350 규격을 PNG 헤더로 확인했습니다. 기본 본문/차콜 대비는 14.87:1, 보조 본문/차콜은 6.98:1, 보조 본문/가장 밝은 카드 표면은 6.11:1, 주요 버튼의 가장 어두운 골드/글자는 6.85:1입니다. 수치 기록은 `qa.json`에 보관했습니다.

HTML은 시안 확인용입니다. 홈 CTA·최근 상담·탐색 탭은 로컬 화면으로 이동하고, 복사 버튼은 브라우저 클립보드를 사용합니다. 캡처 업로드·공유·마이 화면은 실제 서비스에 연결되지 않은 미리보기 동작입니다.
