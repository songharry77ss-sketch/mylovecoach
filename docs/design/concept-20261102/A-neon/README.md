# A-neon · 윙맨 WINGMAN

거의 검정에 가까운 미드나잇 네이비 위에 전기 파랑과 시안의 빛을 얹은 연애 코칭 앱 시안입니다. 자동차 계기판처럼 큰 숫자와 원형 성공 확률 게이지로 핵심을 먼저 보여 주고, 유리 카드와 정렬된 격자로 답장 세 가지를 빠르게 비교하게 합니다. 날개 조형과 금속 테두리의 빛은 화면 가장자리에 배치해 한국어 본문을 또렷하게 유지합니다. 상대를 존중하며 내 말투로 대화를 이어 가는 것이 브랜드의 태도입니다.

**윙맨**은 연애할 때 옆에서 힘을 보태는 든든한 친구를 뜻합니다. 짝을 이루는 날개 상징은 혼자 고민하던 한 문장에 동료가 생긴다는 의미입니다.

## 시각 규칙

| 역할 | 색 |
|---|---|
| 미드나잇 배경 | `#060B18` |
| 유리 카드 표면 | `#142239` |
| 전기 파랑 | `#2F6BFF` |
| 시안 강조 | `#55E7FF` |
| 마젠타 포인트 | `#FF49C7` |

- 본문은 `#F4F8FF`, 보조 글자는 `#AABAD2`. 본문 대비는 4.5:1 이상을 기준으로 합니다.
- 한글은 **Pretendard Bold 700 / Medium 500**, 숫자와 영문은 **Bahnschrift**를 사용합니다.
- 반투명 유리와 여러 겹 그림자, 금속 그라데이션 테두리, 미세 격자·노이즈를 사용합니다. 시안 빛 번짐은 가장자리에 두고 마젠타는 작은 지점에만 씁니다.
- 화면은 393×852 기준으로 구성해 3배인 **1179×2556 PNG**로 출력합니다. 최소 글자는 기준 9px → 출력 27px, 버튼 높이는 기준 40px → 출력 120px입니다. 상태 표시줄과 홈 인디케이터를 포함합니다.
- 아이콘과 `_art/` 조형은 이미지 생성 도구로 제작합니다. 한국어 문구와 수치는 HTML 텍스트로 구성하며, 생성 프롬프트는 `prompts.md`에 기록합니다.

## 타깃에게 매력적인 이유

1. 큰 숫자와 발광 게이지가 자동차·게임 인터페이스의 익숙한 시각 언어를 전달합니다.
2. 캡처 업로드와 답장 비교에 집중한 구조라 첫 화면에서 사용 방법과 효용을 이해하기 쉽습니다.
3. 수집 카드 같은 KKTI 결과는 자기 유형을 표현하고 친구와 공유할 이유를 만듭니다.

## 화면과 예시 데이터

- **홈:** 인사, 캡처 올리기, 상황 입력, 오늘 남은 무료 코칭 1회, 최근 상담, 홈·탐색·마이 탭.
- **코칭 결과:** 상대 메시지 요약, 속마음 가능성, 성공 확률 95%·89%·83%의 답장 카드와 복사, 호감 온도 25°·+10°·미지근.
- **KKTI:** 직진 불도저(선빠폭직), 연락 시작 92%·답장 속도 100%·표현 83%·진도 92%, 잘 맞는 유형 꼬리 흔드는 골댕이(후빠폭직), 공유.

상담 내용과 분석 수치는 컨셉 설명을 위한 예시이며 실제 분석 결과가 아닙니다. 무료 횟수는 `src/lib/billing/plans.ts`의 매일 1회 규칙, KKTI 축·유형·궁합은 `src/lib/kkti.ts`, 온도 구간은 `src/components/coach/heat-gauge.tsx`를 참고했습니다. 새 기능은 추가하지 않았습니다.

## 구현 시 바꿀 컴포넌트

- `src/constants/theme.ts`: 색, 표면, 타이포그래피, 그림자 토큰.
- `src/components/stage/stage.tsx`: 기존 무대 장식을 날개·네온 유리 헤더로 교체.
- `src/components/ui/app-text.tsx`, `button.tsx`: 글자 단계와 버튼 크기·상태.
- `src/app/(tabs)/index.tsx`, `_layout.tsx`, `src/components/crush/crush-list-item.tsx`: 홈의 캡처 우선 구성, 최근 상담, 세 탭.
- `src/components/coach/reply-carousel.tsx`, `heat-gauge.tsx`, `src/app/mind.tsx`: 답장 세 카드, 원형 확률 게이지, 속마음 막대, 온도 표시.
- `src/app/kkti/result.tsx`: 조형을 중심으로 한 결과 카드, 네 축의 스탯과 궁합·공유.

화면은 1179 2556, 보드는 2400 1350을 지정합니다. HTML은 로컬 Pretendard 폰트와 이 폴더의 이미지 파일을 참조합니다.

이 폴더는 검토용 디자인 시안이며 앱 코드를 변경하지 않습니다.

## 최종 검수

PNG를 직접 열어 확인하고 KKTI 금속 링의 상단 잘림과 이미지 경계를 수정했습니다. 홈 상황 입력은 실제 HTML 입력칸으로 구성했고 인사 문장의 말투를 통일했습니다. 한글 폰트와 모든 소재가 정상 로드되며, 화면 밖으로 나간 텍스트와 카드 밖으로 나간 복사 버튼이 없습니다. 화면 3장·아이콘·보드의 출력 크기도 확인했습니다.

최소 화면 글자는 27px, 최소 버튼 높이는 120px입니다. 카드 기준 본문 대비 14.96:1, 보조 글자 8.09:1, 시안 10.82:1이며 밝은 버튼의 글자는 8.94:1입니다. UI 파일은 로컬 검토용 시안으로 실제 AI 분석·공유·라우팅을 연결하지 않았습니다.
