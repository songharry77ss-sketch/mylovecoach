# 답장각 — B-pop

‘이 답장, 각 나왔다.’ 답장각은 답장을 보내기 직전의 망설임을 덜어주는 연애 코칭 앱입니다. 흑백 사진 속 자연스러운 설렘과 탠저린 한 가지 색, 굵고 짧은 한국어 문장으로 브랜드를 만듭니다. 앱 안에서는 캡처 업로드, 상황 입력, 세 가지 답장과 복사처럼 실제 행동을 먼저 보이게 했습니다. 과한 효과 대신 여백과 말풍선으로 대담하고 편한 인상을 냅니다.

## 이름

**답장각**: ‘이 답장, 각 나왔다’에서 가져온 이름. 상대 말투에 맞게, 내 마음을 담아 보낼 답장을 찾는다는 뜻입니다. 영문 표기는 DAPJANG이며 화면에는 한국어 이름을 사용했습니다.

## 색과 글꼴

| 역할 | 값 | 사용 |
|---|---|---|
| 시그니처 | `#FF5A1F` | 업로드 카드, 연애 유형 배경, 큰 제목 |
| 잉크 | `#111111` | 본문, 검정 말풍선, 주요 버튼 |
| 흰색 | `#FFFFFF` | 카드와 검정 버튼의 글자 |
| 바탕 | `#F7F7F4` | 앱 화면의 넓은 여백 |
| 보조 글자 | `#636360` | 설명과 입력 힌트 |
| 짙은 탠저린 | `#C0390C` | 흰 카드의 분석 숫자 |
| 연한 탠저린 | `#FFF0E9` | 추천 답장 배경 |

글꼴은 로컬 **Pretendard Bold / Medium**입니다. 본문 글자 대비는 4.5:1 이상으로 구성했습니다. 탠저린 위에는 검정 글자를 사용합니다. 핵심 조합의 대비는 검정/탠저린 약 6.1:1, 보조 글자/앱 바탕 약 5.6:1, 검정/흰색 약 18.9:1입니다. 생성형 아이콘의 배경에는 미세한 픽셀 색 편차가 있으며, UI의 시그니처 색은 정확한 HEX로 지정했습니다.

## 화면 규칙

- 앱은 393×852 논리 크기를 3배로 렌더링한 1179×2556 PNG입니다. 주요 여백은 8pt 단위, 콘텐츠 패딩은 24pt입니다.
- 주요 카드 모서리는 20–24pt, 메시지와 입력은 16–20pt, 버튼은 알약 형태입니다. 그림자는 보드 목업에만 옅게 사용했습니다.
- 화면 내 최소 글자는 출력 기준 30px, 버튼 높이는 최소 120px입니다. 상태 표시줄과 홈 인디케이터를 포함했습니다.
- 홈: 인사, 캡처 올리기, 남은 무료 2회, 상황 입력, 최근 상담, 홈·탐색·마이.
- 결과: 수연의 메시지, 속마음 가능성 62/23/15%, 무난하게·센스 있게·직진의 세 답장과 성공 확률·복사, 호감 온도 25° 및 +10°.
- 연애 유형: 기존 KKTI의 ‘직진 불도저’를 글자와 말풍선으로 표현했습니다. 공유와 친구 궁합으로 이어집니다.
- 화면의 인물 이름, 대화, 확률, 무료 잔여 횟수는 기능을 보여주는 시안용 예시입니다. 사진은 실존하지 않는 성인 남녀 각 한 명을 생성했습니다.

## 레퍼런스에서 가져온 원칙

범블의 한 가지 브랜드 색, 흑백 인물 사진, 질문 카드와 말풍선의 원칙을 가져왔습니다. 노랑이나 범블의 로고·화면 배치는 사용하지 않았습니다. 토스의 숫자 위계와 여백, 틴더·위피의 자연스러운 사람 중심 첫인상을 참고했습니다. 스토어 사진은 생성한 별도 인물이고 텍스트는 전부 HTML입니다. 3D 오브젝트, 네온, 금속, 유리, 스티커 장식은 사용하지 않았습니다.
