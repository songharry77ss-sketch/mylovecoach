# 애프터 · P-photo

첫 만남 다음, 애프터까지. 실존하지 않는 20대 중반 한국인 남녀의 자연스러운 일상 사진을 중심에 두고, 짧은 한국어 문장과 흰 말풍선으로 대화의 설렘을 보여주는 시안입니다. 큰 사진이 첫인상을 만들고, 선셋 색 버튼이 다음 행동을 안내합니다. 홈에서는 캡처나 상황 입력으로 상담을 시작하고, 결과에서는 답장 세 가지를 한 장씩 넘겨 봅니다. 공유 화면은 사람 사진과 연애 유형을 담은 간결한 카드로 구성했습니다.

## 이름과 문장

- **애프터**: 첫 만남 이후의 대화가 다음 만남으로 이어진다는 뜻입니다. 영문 표기는 AFTER이며, 화면은 한국어 로고타입을 사용합니다.
- 브랜드 문장: **첫 만남 다음, 애프터까지.**
- 스토어 제목: **만남 다음에도, 대화가 이어지게**
- 설명: **카톡 한 장으로, 나다운 답장 3가지**

## 색과 화면 규칙

| 역할 | 값 |
| --- | --- |
| 브랜드 선셋 | `#FF3D6E → #FF8A3D` |
| 블러시 바탕 | `#FFF3F5` |
| 라일락 바탕 | `#F1EDFA` |
| 기본 글자 | `#21191D` |
| 보조 글자 | `#72666D` |
| 작은 강조 글자 | `#A71849` |

- 글꼴은 **프리텐다드 굵게 700 / 중간 500**입니다. 모든 문장은 HTML 텍스트로 구현했습니다.
- 앱 화면은 393×852 논리 크기를 3배로 렌더링한 1179×2556 PNG입니다. 기본 간격은 8pt 격자, 주요 좌우 여백은 24pt입니다.
- 주요 카드 모서리는 24pt 안팎, 버튼은 알약 형태입니다. 그림자는 낮은 불투명도로 제한했습니다.
- 본문 글자는 최종 1179px 폭에서 최소 30px이며, 버튼 높이는 최소 120px입니다. 상태 표시줄과 홈 인디케이터를 포함했습니다.
- 선셋 그라데이션은 아이콘·버튼·브랜드 강조에 사용합니다. 읽는 영역은 밝은 단색으로 유지합니다.
- 본문 대비 기준은 4.5:1 이상입니다. 선셋 버튼의 `#21191D` 글씨는 양 끝 색에서 약 5.03:1 / 7.33:1입니다. 블러시 바탕의 보조 글씨는 약 5.05:1, 작은 강조 글씨는 약 6.76:1입니다.
- 결과 카드는 `무난하게 / 센스 있게 / 직진` 순서입니다. 사진을 흐린 배경 위에 흰 카드를 놓고, 다음 카드 일부와 순서 표시로 넘기는 구조를 보여줍니다.

## 사진과 아이콘

사진 3장은 모두 내장 **image_gen**으로 생성했습니다. 커플 사진에 여성 1명·남성 1명, 단독 사진에 여성 1명·남성 1명으로 총 여성 2명·남성 2명입니다. 모두 실존하지 않는 한국인 성인으로 25~27세를 지정했습니다. 연예인 닮은 얼굴을 지시하지 않았고, 자연광·피부 질감·절제된 필름 색·일상복을 기준으로 만들었습니다. 손과 휴대폰은 프레임 밖에 두었습니다.

아이콘도 내장 image_gen으로 생성했습니다. 하트와 대화 꼬리가 이어지는 하나의 흰 심벌을 선셋 바탕에 놓았으며, 생성 원본을 HTML로 1024×1024 크기에 맞춰 렌더링했습니다. 금속, 과한 광택, 3D 장식은 사용하지 않았습니다. 실제 사용한 생성 프롬프트 원문은 [prompts.md](prompts.md)에 있습니다.

## 레퍼런스에서 가져온 원칙

- **틴더 한국 스토어**: 자연스러운 젊은 성인 사진, 짧고 굵은 제목, 사진 위 이름·대화 칩, 카드 넘김의 리듬.
- **위피**: 밝은 블러시·라일락 바탕, 둥근 흰 카드, 친근한 한국어 대화.
- **토스**: 여백, 분명한 숫자 위계, 한눈에 보이는 주요 행동, 읽기 쉬운 문장.
- **범블**: 일관된 브랜드 색과 사람 중심의 관계 이야기.

참고 앱의 로고·색 조합·화면 배치를 그대로 복사하지 않았습니다. 애프터의 기능과 선셋 색에 맞게 화면을 새로 구성했습니다.

## 프로토타입과 예시 데이터

HTML은 브랜드와 화면을 검토하기 위한 디자인 프로토타입입니다. 답장 카드의 이전·다음 이동, 왼쪽 넘김, 답장 복사 버튼, 오른쪽 넘김 복사를 구현했습니다. 실제 캡처 업로드·분석·결과 공유·궁합·결제 서비스에는 연결하지 않았습니다. 브라우저의 클립보드 권한이 제한되면 직접 텍스트를 선택해 복사할 수 있습니다.

민서·도윤·수연이라는 이름, 대화 내용, 무료 횟수, 성공 확률 92%·89%·85%, 속마음 비율 62%·23%·15%, 호감 온도는 시안용 예시 데이터입니다. 실사용자 정보나 검증된 예측 성능을 나타내지 않습니다. 인물 사진 역시 실제 사용자의 프로필이 아닙니다. KKTI 화면은 작업서에 제시된 기존 유형명 ‘직진 불도저’를 사용했습니다.

## 렌더링

프로젝트 루트에서 실행합니다. 먼저 HTML을 생성한 뒤 화면 PNG를 만들고, 마지막으로 해당 PNG를 사용하는 보드를 렌더링합니다. 프리텐다드 파일과 Edge 실행 경로는 작업서의 로컬 경로를 사용합니다.

```powershell
$conceptDir = 'C:/Users/shsop/mylovecoach-concept-20261102/docs/design/concept-20261102-v2/P-photo'
$renderScript = 'C:/Users/shsop/mylovecoach-codex-tools/render.mjs'
node "$conceptDir/build.mjs"
node $renderScript "$conceptDir/store-1.html" "$conceptDir/store-1.png" 1290 2796
node $renderScript "$conceptDir/screen-1-home.html" "$conceptDir/screen-1-home.png" 1179 2556
node $renderScript "$conceptDir/screen-2-result.html" "$conceptDir/screen-2-result.png" 1179 2556
node $renderScript "$conceptDir/screen-2-result-2.html" "$conceptDir/screen-2-result-2.png" 1179 2556
node $renderScript "$conceptDir/screen-2-result-3.html" "$conceptDir/screen-2-result-3.png" 1179 2556
node $renderScript "$conceptDir/screen-3-kkti.html" "$conceptDir/screen-3-kkti.png" 1179 2556
node $renderScript "$conceptDir/board.html" "$conceptDir/board.png" 2400 1350
```

## 확인과 수정 기록

- 생성된 PNG를 직접 열어 글자 깨짐·겹침·잘림과 사진의 눈·얼굴 표현을 확인했습니다.
- 긴 ‘센스 있게’ 답장도 카드 안에서 두 줄로 읽히는지 별도 PNG로 확인했습니다. 옆 카드가 일부 보이는 것은 넘김을 알리는 의도된 처리입니다.
- 선셋 버튼의 글자색을 진하게 적용해 본문 대비 기준을 맞췄습니다.
- 홈 사진의 머리 위 여백을 확보하고, 스토어 직진 답장의 순서를 `3/3`으로 통일하고, 보드 목업의 화면 비율을 원본에 맞췄습니다. 수정한 홈·스토어·보드 PNG를 다시 렌더링하고 직접 열어 확인했습니다.
- 최종 PNG 8개의 지정 크기, 앱 3화면의 폰트·이미지 로딩, 최소 글자 30px, 모든 버튼 높이 120px 이상을 브라우저에서 확인했습니다. 카드 2/3·3/3 전환과 직진 답장의 복사 요청·확인 표시를 검증했습니다. 복사 요청은 클립보드 대역으로 전달 문구를 확인했으며 실제 운영 서비스와 연결하지 않았습니다.
- 장식성 3D 오브젝트와 의미 없는 영어 라벨을 넣지 않았습니다. 사진·말풍선·기능 정보 중심으로 정리했습니다.

작업 범위는 이 `P-photo` 폴더 안입니다. 앱 코드, 다른 두 시안과 1차 시안은 변경하지 않았으며 git 커밋을 만들지 않았습니다.
