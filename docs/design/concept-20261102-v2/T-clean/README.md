# 럽코 · T-clean

「마음은 담고, 고민은 덜어요.」 카톡 캡처 한 장으로 시작하는 연애 코치를 흰 화면, 넉넉한 여백, 연회색 카드와 큰 한국어·숫자로 정리했습니다. 홈에서는 캡처와 상황 입력이 먼저 보이고, 코칭 결과에서는 상대 메시지·속마음 가능성·답장 3종·호감 온도가 한 화면에서 이어집니다. 세 번째 화면은 작업서에서 허용한 결제 화면을 선택해 하루 2,700원과 평생 29,800원의 차이를 명확하게 보여줍니다. 자연스러운 남녀 사진은 스토어에만 크게 사용했습니다.

## 이름

**럽코 / LUVCO**는 「러브 코치」를 줄인 말이며 러브코미디의 설렘도 담습니다. 화면에는 한글 「럽코」를 로고타입으로 사용합니다.

## 디자인 규칙

- 기본 흰색 `#FFFFFF`, 연회색 카드 `#F2F4F6`, 본문 `#191F28`, 보조 문장 `#626B78`.
- 브랜드 강조·버튼·핵심 숫자는 일렉트릭 바이올렛 `#5B47FF`. 옅은 바이올렛 면은 같은 색 계열의 기능적 강조에만 사용합니다.
- Pretendard Medium 500 / Bold 700. 한국어와 숫자는 모두 HTML 렌더링입니다.
- 393×852 논리 화면을 3배로 출력했습니다. 기본 간격은 8pt, 좌우 여백 24pt, 주요 카드 반경 24pt, 주요 버튼 높이 52pt입니다. 세부 텍스트·아이콘 정렬은 광학 보정했습니다.
- 앱 화면 최소 글자는 11pt → 출력 33px, 버튼 터치 영역은 최소 40pt → 출력 120px입니다. 본문 대비는 `qa-report.json`에서 확인할 수 있습니다.
- 앱 화면마다 작은 3D 말풍선 하나. 금속, 네온, 유리, 장식용 영문 문구, 장식용 그래픽은 넣지 않았습니다.
- 인물 사진은 이미지 생성 도구로 만든 실존하지 않는 26세 한국인 성인 남녀 각 1명입니다. 레퍼런스 사진을 재사용하지 않았습니다.
- 확률·온도·무료 횟수·상담 이름은 시안 데이터입니다. 가격은 작업서 값 그대로 사용했습니다. 새로운 제품 기능은 추가하지 않았습니다.

## 레퍼런스에서 가져온 것

토스에서는 여백, 연회색 카드, 짧은 한국어 문장, 큰 숫자, 한 가지 주요 행동을 가져왔습니다. 틴더·위피에서는 스토어 사진의 자연스러운 표정과 일상적인 설렘을, 범블에서는 한 가지 브랜드 색을 일관되게 사용하는 원칙을 참고했습니다. 각 앱의 로고·실제 사진·화면 배치는 복제하지 않았습니다.

## PNG를 보고 수정한 내용

- 스토어에서 UI 카드와 가까워 보이던 하단 슬로건을 제거했습니다.
- 홈 마지막 상담 행의 구분선을 제거해 하단 탭과 이중으로 보이지 않게 했습니다.
- 답장 3종은 각각 두 줄로 정리하고, 호감 온도까지 한 화면에 보이도록 세로 간격을 조정했습니다.
- 투명 말풍선 외곽의 점을 이미지 생성 도구의 편집으로 줄였습니다.
- 이용권 배지의 배경을 더 밝게 바꿔 작은 글자의 대비를 4.5:1 이상으로 맞췄습니다.
- 최종 PNG의 글자·겹침·잘림, 인물 얼굴과 눈, 버튼·숫자·홈 인디케이터를 직접 열어 확인했습니다.

프로젝트 루트에서 `powershell -File docs/design/concept-20261102-v2/T-clean/render.ps1`을 실행합니다. 작업서에 지정된 Edge 헤드리스 렌더러와 로컬 Pretendard 파일을 사용합니다. 결과물은 이 폴더에만 기록합니다.
