# 콩닥 — M-mascot

콩닥은 답장을 보내기 직전의 고민을 덜어주는 연애 코치예요. 크림 바탕에 체리 레드와 버터 옐로를 놓고, 조금 능청스러운 하트 콩 캐릭터 **콩닥이**를 내 편으로 세웠어요. 홈에서는 캡처 한 장으로 시작하고, 결과에서는 내 말투에 맞는 답장 세 가지를 비교해요. 연애 연습에서는 잘 보낸 한마디에 콩닥이가 바로 반응해요. 화려함은 캐릭터·큰 숫자·눌리는 버튼에 집중하고, 대화 내용은 또렷하게 읽히도록 구성했어요.

## 이름 뜻

- **콩닥**: 좋아하는 사람 앞에서 심장이 뛰는 소리이자, 하트 모양 콩 캐릭터의 생김새예요.
- **콩닥이**: 혼자 고민하지 않도록 옆에서 답장을 함께 고르는 친구예요.
- **슬로건**: 답장 고민은, 콩닥이한테.
- 영문 로고 표기: KONGDAK.

## 색·글꼴·규칙

| 역할 | 색상 | 사용 |
|---|---|---|
| 체리 | `#FF4B5C` | 캐릭터, 캡처 버튼, 진행 표시 |
| 크림 | `#FFF8F0` | 전체 배경과 넓은 여백 |
| 버터 | `#FFD43B` | 추천 표시와 축하 포인트 |
| 잉크 | `#1B1B1F` | 제목, 본문, 체리 버튼의 글자 |
| 진한 체리 | `#B42336` | 크림 위의 강조 글자·수치 |
| 보조 글자 | `#6D625E` | 설명·상태 문구 |

글꼴은 **Pretendard Medium / Bold**예요. 글자는 이미지 생성에 맡기지 않고 HTML로 조판했어요. 화면은 393×852 논리 픽셀을 3배로 렌더링하고, 주요 여백은 8pt 단위를 바탕으로 잡았어요. 앱 화면의 글자는 최소 9px(출력 27px), 버튼은 최소 높이 40px(출력 120px)로 설정했어요. 상태 표시줄, 홈 인디케이터, 둥근 말풍선과 버튼을 같은 규칙으로 사용해요.

체리 버튼에는 잉크 글자를 사용해요. 이 조합의 대비는 약 **5.24:1**이에요. 크림 위에는 잉크(약 16.30:1), 진한 체리(약 6.16:1), 보조 글자(약 5.60:1)를 사용해요. 수치는 지정된 단색 조합의 계산값이에요. 말랑한 클레이 질감은 콩닥이에 집중하고, 화면에는 얕은 아래 그림자만 넣었어요.

## 레퍼런스에서 가져온 것

- **듀오링고**: 캐릭터가 행동을 안내하고 결과에 반응하는 방식, 아래 그림자로 눌리는 느낌을 주는 큰 버튼, 짧은 피드백과 진행 표시.
- **토스**: 한 화면에서 다음 행동을 바로 찾는 위계, 짧은 한국어 문장, 큰 숫자와 충분한 여백.
- 첨부된 한국 App Store 보드는 전달 원칙만 참고했어요. 콩닥이의 외형, 크림·체리·버터 조합, 대화 흐름과 화면 구성은 이 시안을 위해 만들었어요.

## 써 보고 싶게 만드는 장치 3개

1. **시작은 캡처 한 장**: 콩닥이의 인사 아래 가장 큰 버튼을 두고, 무료 상담 횟수와 상황만 적는 경로를 가까이 배치했어요.
2. **고르는 순간의 보상**: 무난하게·센스 있게·직진 답장을 한 화면에서 비교해요. 추천 답장에는 큰 92%와 버터색 카드, 콩닥이 반응을 함께 보여줘요.
3. **잘 보낸 한마디를 남기기**: 연애 연습의 ‘센스 +12점’ 피드백을 대화 바로 아래에 보여줘요. 공감을 잘한 이유와 다음에 물어볼 말을 짧게 알려주고, 공유할 수 있는 카드 형태로 구성했어요.

## 새 기능 제안

**연습 카드 공유 — 1개**

기존 연애 연습에서 받은 콩닥이 피드백을 카드로 저장하거나 공유하는 확장이에요. `screen-3-practice`의 ‘연습 카드 공유’ 버튼과 피드백 카드로 표현했어요. 연속 기록 기능은 넣지 않았어요. ‘대화 3 / 5’와 진행 막대는 현재 연습 안에서의 진행 상태를 나타내요.

## 파일

| 파일 | 크기 / 내용 |
|---|---|
| `icon.png` | 1024×1024 · 이미지 생성으로 만든 앱 아이콘 |
| `store-1.png` | 1290×2796 · 브랜드 첫인상과 답장 코칭 미리보기 |
| `screen-1-home.png` | 1179×2556 · 캡처 업로드와 최근 상담 |
| `screen-2-result.png` | 1179×2556 · 속마음, 답장 세 가지, 호감 온도 |
| `screen-3-practice.png` | 1179×2556 · 가상 상대와 연애 연습, 콩닥이 피드백 |
| `board.png` | 2400×1350 · 브랜드와 화면 4장을 묶은 공유용 보드 |

| `assets/` | 콩닥이 포즈와 아이콘 이미지 자산 |
| `prompts.md` | 이미지 생성 프롬프트와 제작 방식 |

이 결과물은 실제 앱에 연결되지 않은 **정적 디자인 시안**이에요. 대화·무료 횟수·성공 확률·속마음 비율·호감 온도·연습 점수는 화면을 설명하기 위한 예시예요.

## 최종 검수

최종 PNG 6장을 직접 열어 확인했어요. 결과 화면의 캐릭터와 ‘선 긋는 중’ 문구가 가까웠던 부분을 분리하고, 연습 카드 공유 버튼이 카드 안에 충분히 들어오도록 하단 여백을 늘렸어요. 보드의 화면 목업 비율도 원본에 맞췄어요.

`audit.mjs` 실행 결과 PNG 6장 규격, 폰트·이미지 로딩, 앱 화면 내 텍스트 경계, 버튼 최소 높이 120px 검사가 모두 통과했어요. 앱 화면 글자는 최소 27px이며, HTML의 실제 전경·배경색으로 계산한 최소 텍스트 대비는 4.90:1이에요. 세부 결과는 `qa-report.json`에 있어요.

## 다시 렌더링하기

저장소 루트에서 PowerShell로 실행해요. 먼저 HTML을 재생성하고 앱 화면 3장과 스토어 이미지를 렌더링한 다음, 그 PNG를 사용하는 보드를 마지막에 렌더링해요.

```powershell
$conceptDir = Join-Path (Get-Location) 'docs/design/concept-20261102-v3/M-mascot'
$renderer = 'C:/Users/shsop/mylovecoach-codex-tools/render.mjs'
node "$conceptDir/build.mjs"
node $renderer "$conceptDir/screen-1-home.html" "$conceptDir/screen-1-home.png" 1179 2556
node $renderer "$conceptDir/screen-2-result.html" "$conceptDir/screen-2-result.png" 1179 2556
node $renderer "$conceptDir/screen-3-practice.html" "$conceptDir/screen-3-practice.png" 1179 2556
node $renderer "$conceptDir/store-1.html" "$conceptDir/store-1.png" 1290 2796
node $renderer "$conceptDir/board.html" "$conceptDir/board.png" 2400 1350
```

지정된 Edge 헤드리스 렌더러와 저장소의 Pretendard 폰트 경로를 사용해요. 아이콘과 캐릭터 이미지는 HTML 재생성으로 바뀌지 않으며, 프롬프트는 `prompts.md`에서 확인할 수 있어요.
