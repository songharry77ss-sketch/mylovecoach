# 청신호 · G-glass

밝은 강변 사진 위로 투명한 유리 카드가 떠 있는 카톡 답장 코치예요. 사진에는 설레는 순간을, 카드에는 지금 해야 할 일만 담았어요. 홈에서 캡처 한 장을 올리고, 상대의 속마음을 확인한 뒤 세 가지 답장 중 내 말투에 맞는 것을 복사해요. 맑은 사진, 짧은 문장, 초록 신호가 같은 방향으로 이어지도록 만들었어요.

## 이름 뜻

**청신호**는 “그 사람, 청신호일까?”라는 질문에서 출발해요. 관심 있을 가능성을 읽는 기능과 바로 이어지는 이름이에요. 상징은 신호의 원과 말풍선을 합친 단일 마크예요. 영문 로고 표기는 GREEN LIGHT이며 이번 화면은 한글 로고로 통일했어요.

## 색·글꼴·규칙

- 브랜드 그린 `#14C38E`: 주요 버튼, 선택 상태, 신호에만 사용해요. 밝은 초록 위 글자는 잉크색으로 읽혀요.
- 잉크 `#0E1116`, 바탕 `#F4FAF8`, 보조 글자 `#45534F`. 숫자용 짙은 그린 `#076B50`은 밝은 면에서도 대비를 확보해요.
- 생성 아이콘의 배경은 `#14C38E`에 가까운 생성색이에요. UI와 보드의 색 견본은 정확한 HEX를 사용해요.
- 프리텐다드 미디엄(500) / 볼드(700). 저장소의 OTF를 로컬 `@font-face`로 읽어요. 영어 장식 라벨은 없어요.
- 주요 여백은 8px 배수(24·32·40·48·64·72)를 기준으로 맞췄어요. 숫자는 크게, 설명은 짧게 둬요.
- 앱/스토어의 최소 글자 26px, 버튼 높이 최소 120px. 앱 3장에는 상태 표시줄, 다이내믹 아일랜드, 홈 인디케이터가 있어요.
- 유리 면: 흰색 24%(일부 28%), `backdrop-filter: blur(36px) saturate(180%)`, 위쪽 1px 하이라이트, 옅은 그림자. 본문 뒤에는 사진과 별도인 밝은 베일을 두어 대비를 확보해요.
- 사진은 실존하지 않는 20대 중반 한국인 성인 남녀 각 1명. 자연광, 필름 질감, 손과 휴대폰 화면은 프레임 밖이에요. 사진 원본은 변형하지 않고 HTML에서 크롭·마스크·베일만 적용했어요.
- 금속·크롬·네온 발광·게임 장식은 사용하지 않았어요. 기본 아이콘은 단순한 SVG 선으로 그렸어요.

## 레퍼런스에서 가져온 것

- **로켓**: 가까운 사람의 사진이 화면의 중심이 되는 친밀감, 짧고 분명한 한 가지 행동.
- **토스**: 설명보다 먼저 보이는 핵심 수치, 읽기 쉬운 한국어, 넉넉한 터치 영역.
- **틴더**: 밝고 자연스러운 성인 인물 사진이 먼저 전하는 감정, 한 문장으로 읽히는 첫 장.
- **브리프의 리퀴드 글래스 방향**: 밝은 사진 위의 흐림·채도·얇은 하이라이트. 레퍼런스 로고, 화면 배치, 브랜드 색 조합은 가져오지 않았어요.

2차의 보드와 스토어 3종을 직접 열어 확인했어요. G-glass는 사진이 작은 카드 안에만 머물지 않고 화면 뒤까지 이어지고, 그 사진의 색이 유리를 통과하도록 만들었어요.

## ‘써 보고 싶게’ 만드는 장치 3개

1. **시작은 한 번만.** 홈의 가장 강한 버튼은 ‘캡처 올리기’예요. 무료 2회를 바로 보여 주고, 캡처가 없으면 ‘상황만 적어볼래요’로 이어져요.
2. **읽고 바로 복사해요.** 속마음의 ‘62%’와 답장 성공 확률 ‘84·92·78%’를 서로 다른 영역에 뒀어요. 세 답장은 긴 보고서 대신 독립된 대화 카드로 한 화면에서 비교하고 각각 복사해요. 추천 답장은 얇은 초록 테두리로 구분해요. 호감 온도는 `25° → 35° / +10°`로 변화가 보여요.
3. **나를 표현하는 한 장.** 카톡 연애 유형을 ‘좋으면, 먼저 말해요.’라는 짧은 자기소개로 바꿨어요. 사진과 실제 같은 한 문장으로 구성한 카드 아래에 결과 공유와 친구 궁합을 배치했어요.

## 새 기능 제안

없음. 캡처/상황 입력, 속마음 분석, 답장 3가지·복사, 호감 온도, KKTI 공유·친구 궁합만 사용했어요. 위젯·연속 기록 등 새 기능은 넣지 않았어요.

## 시안 범위

화면에 쓰인 이름·대화·확률은 일관성을 맞춘 시안용 예시예요. 실제 예측 성능을 검증한 숫자가 아니에요. HTML은 고정 크기 디자인 원본이며 답장 복사 3개만 로컬 미리보기에서 동작해요(브라우저의 클립보드 권한 필요). 업로드, 공유, 궁합 등은 화면 구성만 제안해요.

## 재렌더링

현재 Windows 작업 환경에서 실행해요. Edge, 도구 폴더의 Playwright, Python의 Pillow·NumPy를 사용해요. 이미 생성한 이미지 원본을 재사용하므로 다시 이미지 생성할 필요는 없어요.

```powershell
& .\docs\design\concept-20261102-v3\G-glass\render.ps1
```

`build.mjs` → 앱 3장·스토어 PNG → 보드 PNG 순서로 렌더링해요. 결과물과 검사 기록은 모두 이 폴더 안에 저장해요.

## 검수와 고친 점

- PNG 6개를 직접 열어 글자, 얼굴, 잘림, 목업 배치를 확인했어요.
- 스토어 사진 시작의 수평 경계는 CSS 마스크로 지웠어요.
- 공유 카드에서 여성의 얼굴을 가리던 페이드를 아래로 내렸어요.
- 홈 제목 뒤 잎 부분은 밝게 처리하고, 사진 위 보조 라벨의 잉크를 조정했어요.
- 폰트 로드, 이미지 로드, 캔버스 밖 텍스트, 최소 글자/버튼 크기를 `qa/layout-report.json`에 기록해요.
- 글자를 숨긴 렌더에서 각 텍스트 줄의 전체 사각형을 픽셀 단위로 검사해 사진과 유리 합성 뒤의 대비를 확인했어요. 이 검사는 글자 획뿐 아니라 사각형 전체의 가장 낮은 대비를 보는 보수적인 검사예요. 수치는 `qa/contrast-report.json`에 있어요.

이미지 생성 프롬프트와 원본 출처는 [prompts.md](prompts.md)에 있어요.
