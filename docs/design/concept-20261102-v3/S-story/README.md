# 찐텐 · S-story

찐텐은 카톡 답장 앞에서 멈춘 순간을 가볍게 풀어 주는 연애 코칭 앱 시안입니다. 검정 바탕에 핫핑크·라일락·크림 색면, 크게 읽히는 한국어, 자연스럽게 웃는 인물 스티커를 조합했습니다. 캡처 한 장을 올리면 상대의 말과 속마음을 읽고, 내 텐션에 맞는 답장 세 가지를 고르는 흐름입니다. 결과는 다섯 장의 이야기로 이어지며, 카톡 연애 유형은 그대로 공유하고 싶은 한 장으로 남습니다.

## 이름과 문장

- **찐텐**: ‘진짜 텐션’의 줄임말. 내 말투와 마음이 살아 있는 답장을 뜻합니다.
- 영문 로고 표기: **JJINTEN**.
- 슬로건: **가짜 텐션 말고 찐텐 답장.**
- 화면에서는 짧고 친근한 한국어를 사용합니다. 일반 기능에 영문 라벨을 붙이지 않았습니다.

## 색·글꼴·화면 규칙

| 역할 | 색 |
| --- | --- |
| 바탕과 색면 위 글자 | 검정 `#0A0A0A` |
| 캡처 시작·추천 답장 | 핫핑크 `#FF3D8B` |
| 내 유형·호감 온도 | 라일락 `#B69CFF` |
| 기본 본문·말풍선·버튼 | 크림 `#FFF1DC` |

글꼴은 **Pretendard Bold 700 / Medium 500**입니다. 프로젝트의 `api/_assets/fonts/Pretendard-Bold.otf`, `Pretendard-Medium.otf`를 HTML에서 불러옵니다. 생성 이미지에는 UI 글자를 넣지 않고, 제목·버튼·메시지·숫자는 HTML로 구성했습니다.

주요 간격은 8px 단위를 바탕으로 설계했습니다. 글자 간격, 베이스라인, 기울어진 스티커와 기기 프레임에는 광학 보정을 적용했습니다. 1179px 폭의 앱 원본에서 최소 글자는 26px, 버튼·이동 컨트롤 높이는 120px 이상입니다. 발표 보드의 기기 화면은 해당 원본을 축소해 배치합니다.

색면 안의 글자는 검정으로 고정합니다. 검정과 핫핑크의 대비는 **5.93:1**, 라일락은 **8.66:1**, 크림은 **17.79:1**입니다. 평평한 색면과 선명한 경계를 사용하며 금속, 크롬, 네온 번짐, 게임 HUD 효과는 사용하지 않습니다. 앱 화면에는 상태 표시줄과 홈 인디케이터를 포함합니다.

인물은 이미지 생성 도구로 제작한 실존하지 않는 한국인 성인 남성 27세·여성 26세입니다. 자연광과 필름 느낌, 일상적인 옷차림, 자연스러운 표정을 사용했습니다. 인물 원본은 실제 알파 채널이 있는 컷아웃이며 HTML에서 기울여 배치합니다.

## 레퍼런스에서 가져온 것

- **인스타그램 한국 App Store 보드**: 장면마다 짧게 읽히는 문장, 사람의 표정과 스티커를 통한 친근함, 스토리 진행의 익숙한 감각.
- **스포티파이 한국 App Store 보드**: 큰 숫자와 단순한 색면이 만드는 즉각적인 보상, 나를 설명하는 결과를 한 장으로 공유하는 방식.

레퍼런스의 로고, 고유한 색 조합, 화면 배치와 장식은 복제하지 않았습니다. 찐텐의 지정 팔레트와 실제 코칭 기능에 맞춰 화면을 구성했습니다. 2차 시안의 보드와 스토어 이미지를 확인하고, 인물 컷아웃·숫자 크기·다크 색면의 리듬을 발전시켰습니다.

## 써 보고 싶게 만드는 장치 3개

1. **첫 행동이 바로 보여요.** 홈의 가장 큰 핫핑크 블록에 ‘캡처 올리기’를 배치하고, 상황 적기와 오늘 남은 무료 횟수를 가까이 둡니다. 최근 상담의 원형 이니셜과 호감 온도는 이어 볼 대화를 찾게 해 줍니다.
2. **넘길 때마다 하나씩 알아가요.** 다섯 칸 진행 막대와 앞뒤 이동으로 상대의 말, 속마음, 답장, 온도를 읽습니다. 답장 세 가지는 확률 숫자와 색으로 빠르게 비교하고 바로 복사할 수 있습니다.
3. **내 유형을 한 장으로 남겨요.** ‘직진 불도저’라는 큰 한국어 타이포, 인물 스티커와 짧은 대화를 조합한 카톡 연애 유형 카드를 제공합니다. 별도의 1080×1920 공유 이미지도 포함했습니다.

## 결과 화면과 프로토타입 범위

스토리 순서는 **1/5 상대가 보낸 말 → 2/5 속마음 → 3/5 답장 3가지 → 4/5 호감 온도 → 5/5 선택한 답장 복사**입니다. 결과 HTML에서 이전·다음 버튼 또는 키보드 좌우 화살표로 이동할 수 있습니다. 주소 뒤에 `?step=1`부터 `?step=5`까지 붙여 각 장면을 바로 열 수 있습니다.

기본 `screen-2-result.png`는 **3/5 답장 선택 화면**입니다. 한 장만 공유해도 상담 맥락이 보이도록 상대 메시지, 속마음 세 가지 확률, 답장 세 가지와 복사 버튼, 호감 온도 요약을 함께 보여 줍니다. 다른 장면은 `story-1.png`, `story-2.png`, `story-4.png`, `story-5.png`로 제공합니다. 답장을 복사하면 마지막 장면에도 해당 답장과 확률이 반영됩니다.

이 결과물은 **정해진 예시를 사용하는 디자인 프로토타입**입니다. 수연·민준이라는 이름, 대화, 성공 확률과 온도는 시안용 예시입니다. 실제 캡처 분석, AI 추론, 결제, 계정 저장을 연결한 서비스 구현은 포함하지 않습니다. 제공된 버튼은 화면 이동, 예시 안내 또는 답장 복사 동작을 보여 줍니다.

## 새 기능 제안

**없음.** 답장 세 가지·속마음 분석·호감 온도·최근 상담·카톡 연애 유형·공유·친구와 궁합 등 작업 문서에 있는 기능을 사용했습니다. 다섯 장의 스토리는 기존 코칭 결과의 표시 방식이며 별도의 새 기능은 아닙니다.

## 재생성과 검증

이 폴더에서 아래 순서로 실행합니다. Node.js, 로컬 Edge, `C:/Users/shsop/mylovecoach-codex-tools/`의 Playwright 렌더 도구와 프로젝트 글꼴 경로를 사용합니다.

```powershell
node .\build.mjs
& .\render.ps1
node .\audit.mjs
```

- `build.mjs`: 화면의 HTML 원본을 생성합니다.
- `style.css`: 색, 글꼴, 레이아웃과 기기 목업 스타일을 정의합니다.
- `interactions.js`: 스토리 이동, 답장 선택·복사, 안내 메시지를 담당합니다.
- `render.ps1`: 지정된 크기로 HTML을 PNG로 렌더링합니다.
- `audit.mjs`: 글꼴·이미지 로드, 텍스트 경계, 최소 글자 크기, 컨트롤 높이, 스토리 이동과 복사를 점검하고 `qa-report.json`을 기록합니다. 나머지 스토리 장면 PNG도 생성합니다.

PNG를 직접 열어 한글, 여백, 색 대비와 인물 표현을 확인했습니다. 스토어의 크림 말풍선에는 검정 글자색을 명시했고, 결과의 마지막 장면은 선택한 답장과 연결했습니다. 실제 검증 수치와 동작 결과는 `qa-report.json`에서 확인할 수 있습니다.
