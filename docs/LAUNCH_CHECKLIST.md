## 개인정보·탈퇴에서 아직 확정할 것

- 회원가입은 선택입니다. 비회원 맛보기 1회, 회원 보너스 3회+매일 1회이며 기존 무가입 앱의 체험 3회+매일 1회와 다릅니다.
- Google은 `openid email profile`만 사용합니다. 회원 식별자·이메일과 제공되는 이름·프로필 사진 주소가 Supabase Auth에 보관될 수 있고 사진 파일을 별도로 저장하지는 않습니다.
- 회원과 연결되는 이용 기록은 계속 선택 동의입니다. 기존 App Store 8유형·Play 9유형 저장 답안이 신규 회원 수집까지 반영한 답안은 아닙니다.
- Supabase는 FREE 플랜이며 DB 감사 로그 기록 꺼짐·감사 표 0행을 확인했습니다. 외부 Auth Audit Logs는 공식 Free 1시간 기준으로 회원 정보의 탈퇴 시 삭제와 구분합니다. 현재 DB 감사 행의 미정 보관 문제는 운영에 해당하지 않으며, 향후 DB 기록을 켤 때 별도 파기 기준이 필요합니다([AUTH_SETUP.md](AUTH_SETUP.md)).
- 현재 확인 기록상 Kakao Admin 설정 부재, Google revoke 미구현입니다. Apple 취소 자격증명의 존재만 확인했으므로 실기 취소 성공을 검증합니다.
- 앱 회원 삭제와 스토어 구독 취소는 별개입니다. 자동갱신 결제 지속과 구독 관리 경로를 안내합니다.
- Google 홈페이지 소유권 확인 후 콘솔 안내의 반영 시간을 기다려 브랜딩을 재검증·게시합니다. 계정 선택 화면 도달과 회원가입 완료를 구분합니다.

## AI 동의·기존 앱 호환성

기존 iOS 1.0(116)은 AI 분석 동의 시트가 없는 과거 빌드입니다. AI 동의를 포함한 1.0.1(121)은 심사 대기 상태이고, 최신 기본 브랜치에는 AI 동의·신고·회원가입·Google 코드가 포함됩니다.

- 새 AI 기능 호출은 동의 시트에서 Google·전송 내용·목적·보관 안내를 확인하고 동의한 뒤에만 시작합니다. 이용 기록 수집은 별도의 선택 동의입니다.
- Gemini 유료 서비스는 제품 개선에 입력·출력을 쓰지 않는 약관 적용을 확인했습니다. 남용 방지용 텍스트 입력·맥락·출력 55일 보관과 표시된 내용의 인적 검토는 별도입니다. 원본 사진 파일을 반드시 55일 보관한다고 단정하지 않습니다.
- `AI_CONSENT_REQUIRED=1`은 동의 헤더 없는 예전 앱을 HTTP 426으로 막습니다. 새 버전이 실제 배포·설치 가능해진 뒤 적용 범위를 확인해 별도 결정하며 테스트 빌드 업로드만으로 켜지 않습니다.
- 예전 미리 체크된 이용 기록은 두기로 결정한 기록을 유지합니다. 최신 앱은 예전 동의를 다시 묻고, 해당 기기에 「예전에 보낸 이용 기록 지우기」를 제공합니다.
- iOS 117·TestFlight 118/119 등 중간 동의 빌드를 거친 기기는 예전 기록 삭제 표시가 나타나지 않을 수 있어 메일 삭제 요청을 안내합니다. 118/119는 TestFlight 전용 무제한 빌드였으므로 최신 판매용 빌드로 간주하지 않습니다.

- 신고는 기기 ID·IP 없이 저장하며 하루 300건·DB 400MB 상한, 신고일로부터 1년 보관 뒤 신고 전용 예약 작업으로 파기합니다.

- 신규 DB 변경이 필요하면 `delete_device(text)`, `take_quota(text,integer,bigint)`, `purge_old_records()`의 회원 정리 줄과 신고 정리 예약을 먼저 확인합니다. 기존 신고 SQL 완료를 이유로 추가 스키마 실행이 필요한 것으로 보지 않습니다.

- 공개 방침 시행일·개정 이력은 실제 배포 날짜와 변경 내용에 맞춥니다.
