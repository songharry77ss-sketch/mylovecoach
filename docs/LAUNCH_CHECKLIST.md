- AI 요청의 기능 종류·모델·상태/오류 코드·토큰 수·시도 수·종료 이유·캡처 첨부 여부·처리 시간은 선택 이용 기록과 별도로 Vercel 운영 진단에 남습니다. 현재 Hobby의 Runtime Logs 1시간·Drains 0개이며 새 장기 보관 설정은 추가하지 않았습니다. 유료 IAP 서비스의 Hobby 상업적 이용 제한 해소를 위한 요금제 검토는 미완료입니다.

## AI 동의·기존 앱 호환성

기존 iOS 1.0(116)은 AI 분석 동의 시트가 없는 과거 빌드입니다. AI 동의를 포함한 1.0.1(121)은 10월 9일 출시를 확인했지만 Google·회원가입 추가 전 소스입니다. 최신 기본 브랜치의 회원가입·Google 코드를 담을 1.0.2는 아직 빌드를 업로드하지 않은 초안입니다.

- 새 AI 기능 호출은 동의 시트에서 Google·전송 내용·목적·보관 안내를 확인하고 동의한 뒤에만 시작합니다. 이용 기록 수집은 별도의 선택 동의입니다.
- Gemini 유료 서비스는 제품 개선에 입력·출력을 쓰지 않는 약관 적용을 확인했습니다. 남용 방지용 텍스트 입력·맥락·출력 55일 보관과 표시된 내용의 인적 검토는 별도입니다. 원본 사진 파일을 반드시 55일 보관한다고 단정하지 않습니다.
- `AI_CONSENT_REQUIRED=1`은 동의 헤더 없는 예전 앱을 HTTP 426으로 막습니다. 새 버전이 실제 배포·설치 가능해진 뒤 적용 범위를 확인해 별도 결정하며 테스트 빌드 업로드만으로 켜지 않습니다.
- 예전 미리 체크된 이용 기록은 두기로 결정한 기록을 유지합니다. 최신 앱은 예전 동의를 다시 묻고, 해당 기기에 「예전에 보낸 이용 기록 지우기」를 제공합니다.
- iOS 117·TestFlight 118/119 등 중간 동의 빌드를 거친 기기는 예전 기록 삭제 표시가 나타나지 않을 수 있어 메일 삭제 요청을 안내합니다. 118/119는 TestFlight 전용 무제한 빌드였으므로 최신 판매용 빌드로 간주하지 않습니다.

## AI 답변 신고·DB 완료 기록

2026-10-08 `supabase/ai_report.sql` 적용 후 RLS 켜짐·정책 0개·트리거 1개, 정리 작업 cron 2개 활성 및 기존 `purge_old_records()` 정의 해시 유지가 확인됐습니다. 개인정보 안내를 포함한 `41e4439`를 [배포 워크플로 37722883625](https://github.com/songharry77ss-sketch/mylovecoach/actions/runs/37722883625)로 배포하고, 합성 신고 HTTP 201·관리자 조회·시험 행 삭제까지 확인했습니다. 이는 당시 완료 기록이며 이후 최신 배포 결과와 구분합니다.

- 신고는 기기 ID·IP 없이 저장하며 하루 300건·DB 400MB 상한, 신고일로부터 1년 보관 뒤 신고 전용 예약 작업으로 파기합니다.
- 신고 진입점은 답장 카드, 연애 연습의 최신 상대 말/말풍선/피드백, 상대 분석 보고서, 속마음 풀이, 마이 탭입니다. 연습 「끝내기」와 신고 깃발을 구분합니다.
- 운영 DB를 확인하지 않고 과거 `schema.sql`을 다시 실행하지 않습니다. 회원 관련 파기(`bonus_spent`·`member_device`)가 빠진 정의로 덮어쓰지 않도록 현 정의와 비교합니다.
- 신규 DB 변경이 필요하면 `delete_device(text)`, `take_quota(text,integer,bigint)`, `purge_old_records()`의 회원 정리 줄과 신고 정리 예약을 먼저 확인합니다. 기존 신고 SQL 완료를 이유로 추가 스키마 실행이 필요한 것으로 보지 않습니다.
- 주 1회 신고를 검토하고 반복 유형에 맞춰 AI 규칙·안전 설정을 조정합니다.
- 공개 방침 시행일·개정 이력은 실제 배포 날짜와 변경 내용에 맞춥니다.
