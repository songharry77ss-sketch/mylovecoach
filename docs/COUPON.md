# 쿠폰 코드

코드를 넣으면 며칠 동안 무제한으로 쓰게 해 준다. 2026-11-19 「FINISH 입력하면 3일 무제한」으로 시작했다.

## 지금 있는 코드

| 코드 | 무제한 | 끝나는 날 |
| --- | --- | --- |
| `FINISH` | 3일 | 없음 |

## 동작

- **입력 위치:** 마이 → 이용권·계정(웹은 「계정」) → 「쿠폰 코드 입력」, 결제 화면 아래 「쿠폰 코드」, 링크 `/coupon?code=FINISH`(코드가 미리 채워짐).
- **코드 확인:** 서버가 한다. `POST /api/team { coupon }` 이 `api/_coupon.ts` 의 표를 보고 며칠인지 돌려준다. 대소문자, 띄어쓰기, `-` 는 무시한다.
  - 철자 맞히기를 막으려고 IP 하나당 10분에 10번까지만 받는다.
  - 기기 ID 는 보내지 않는다.
- **지급:** 앱이 이 기기의 하루 이용권 칸(`wallet.passUntil`)에 N일을 더한다.
  - 하루 이용권을 쓰는 중이면 남은 시간 뒤로 이어 붙인다.
  - 같은 코드는 이 기기에서 한 번만 받는다(`granted` 에 `coupon:코드`).
  - 하루 이용권처럼 이 기기에만 저장된다. 앱을 지우면 같이 사라지고, 다시 깔면 한 번 더 받을 수 있다.
- **화면 표시:** 24시간보다 길게 남으면 「무제한 이용권 · 11월 22일 오후 3:42까지」로 날짜까지 보여 준다.
- **iOS 앱에서는 보여 주지 않는다.** App Store 심사 지침 3.1.1 은 앱 기능을 자체 코드(라이선스 키 등)로 여는 걸 막는다. 쿠폰은 웹과 Android 앱에서만 쓸 수 있다(`src/lib/billing/coupon.ts` 의 `couponSupported`).
  - iOS 에서 비슷한 걸 하려면 App Store Connect 의 「오퍼 코드」를 써야 한다.
  - 1.3.1 「이번 버전의 새로운 기능」 첫 줄(쿠폰)은 Android 용이다. iOS 로 1.3.1 문구를 낼 때는 그 줄을 빼고 낸다.

## 코드 더하기·끝내기

`api/_coupon.ts` 의 `COUPONS` 를 고치고 웹을 배포한다(`vercel.yml`). 앱 업데이트는 필요 없다.

```ts
export const COUPONS = {
  FINISH: { days: 3 },
  WELCOME7: { days: 7, until: '2026-12-31T15:00:00Z' }, // 2027-01-01 00:00 KST 부터 못 받음
};
```

저장소가 공개라 코드 이름도 공개된다. 널리 퍼져도 괜찮은 홍보용 코드만 둔다.

## 기록

- 앱 이벤트 `coupon_open { link }` 과 `coupon_result { result: granted|rejected, code?, days? }` 를 남긴다(분석 동의한 기기만).
