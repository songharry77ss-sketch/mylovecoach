## 원본 사용과 구성 조정

- 앱 UI는 `../ios-6.7/`의 원본 PNG를 CSS로 자르고 확대·회전한 것만 사용한다. AI로 앱 UI나 한글을 생성하지 않았다. 정확한 크롭 좌표는 [manifest.json](manifest.json)에 기록했다.
- 3장의 50%는 원본의 **호감 및 친근감 표현** 예시다. 원본의 “연애 시그널로 확신하긴 이른 단계” 요약을 함께 보인다. 부채꼴 카드가 설명문을 가리지 않도록 각 막대 카드는 제목·수치·막대만 잘라 썼다.
- 4장의 두 폰은 모두 `4-report.png`다. 별도 온도 화면을 만들지 않고 오른쪽 폰에 같은 보고서 영역을 확대했다. 장식용 `0°→25°`는 원본의 시작 온도·현재 온도를 그대로 강조했다. `+10°`, `50%`도 원본 값과 같다.
- `6-home.png`에는 입력창이 없으므로 2차와 같이 `1-chat-replies.png`의 `(178,2568,1114,2734)` 입력창을 사용했다. 폰을 추가하지 않아 메뉴·입력 콜라주에 시선이 모이도록 했다.
- 5장은 X·Threads 등 공유 로고가 있는 하단을 제외하고 원본의 결과 카드까지만 사용했다.
- 레퍼런스 보드는 구도 다양성만 참고했다. 레퍼런스의 화면·로고·인물은 사용하지 않았다.

## 인물 사진

내장 `image_gen`으로 **새 단색 배경 스튜디오 사진 6장**을 만들었다. 여성 2명·남성 3명의 단독 사진과 여성·남성 친구 사진 1장이다. 전원 가상의 27세 한국인 성인으로 요청했고, 얼굴·머리·옷·동작을 다르게 구성했다. 단정한 긴소매 복장, 노출 없음, 글자·로고 없음, 휴대폰 뒷면만 보이도록 생성했다. 손·눈·휴대폰 방향을 시각 검토했다.

## 검증

iOS·Play 개별 이미지와 전체 연락 시트, 230px 축소본, 2차 비교본을 시각 확인했다. 3장 막대 카드의 설명 가림, 5장 칩 가림, 6장 얼굴·제목 가림을 수정한 최종본이다. 제목은 1290 기준 iOS 140px, Play 구성 134px이고, 위 150px·아래 120px 안전 여백을 지킨다.

최종 검증은 **레이아웃 12/12 통과, PNG 23개 전부 3,000,000바이트 이하, 보호 파일 170개 불변**이다. 최대 PNG는 2,458,610바이트, 최대 스토어 개별 이미지는 1,540,500바이트다. 세부 수치는 `validation-files.json` 및 `validation-layout.json`, 최종 시각 검토는 [visual-qa.md](visual-qa.md)에 기록했다. 앱 코드·기존 이미지·1·2차 파일·렌더 도구는 변경하지 않았다. 커밋·push·스토어 업로드·서버 작업은 하지 않았다.
