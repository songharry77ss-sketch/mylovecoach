## 이미지·UI 출처

- 재사용 사진은 2차 `_photos/01-cafe-woman.png`, `02-neon-man.png`, `03-lamplight-woman.png`, `07-friends.png`, `08-sofa-man.png`를 상대 경로로 직접 참조한다. 원본 파일은 복사하거나 수정하지 않았다.
- 신규 사진 3장은 내장 **imagegen**으로 생성했다. 20대 중반의 가상 한국인 성인, 단정한 옷, 노출 없음, 특정 연예인 닮은꼴을 요청하지 않음, 휴대폰 뒷면만 노출, 손·눈 검수 조건을 적용했다.
- 앱 화면은 `../ios-6.7/*.png` 원본만 CSS로 균등 확대하고 잘랐다. 문구·수치·UI를 재작성하지 않았다. `manifest.json`에 크롭 좌표와 원본 SHA-256을 기록했다.
- 3번 큰 **50%**에는 원본 의미인 **호감 및 친근감 표현**을 붙였다. 확정된 연애 성공률로 표현하지 않았다.
- 4번 **0° → 25°**는 원본 게이지의 `0°에서 시작`과 현재 `25°`를 강조한 값이다.
- 6번 입력창은 `1-chat-replies.png`의 `(178,2568,1114,2734)`, 메뉴는 `6-home.png`의 `(45,300,1245,970)`에서 가져왔다.
- 5번은 KKTI 결과 카드만 크롭하여 원본 하단의 외부 공유 서비스 로고를 제외했다.

## 검증

- 레이아웃: iOS·Play **12/12 통과**, 오류 0. Pretendard 로딩, 제목 138px / 134px(1290px 설계 폭 기준), 글자 잘림, 위 150px·아래 120px 안전 여백, 실제 앱 이미지 출처 확인.
- 대비: 별도 합성 배경 측정 **110개 영역**, 최소 **5.4599:1**, 4.5:1 미만 0개. 사진 위 제목에는 갈색 그라데이션을 보강했다. 회전 스티커는 글리프 마스크 아래 배경으로 측정했다. 원본 앱 캡처 내부 텍스트는 재디자인 대상이 아니므로 이 오버레이 대비 검사에 포함하지 않는다.
- 파일: **19/19 통과**, 본편 치수·비교판 치수·모든 PNG 용량 확인. 원본 앱 캡처 6개의 해시 일치.
- 육안: 본편, 두 비율의 연락판, 230px 썸네일, 전후 비교판을 확인했다. 얼굴·손, 실제 UI 크롭, 폴라로이드, 모자이크, 제목과 라벨 간격을 확인했다.
- Git 상태: 기존 추적 파일 변경 없음. 신규 v4 폴더와 4차 작업서만 작업 대상이며, 1~3차 작업서·결과는 수정하지 않았다. 커밋·push·스토어/서버 작업 없음.
