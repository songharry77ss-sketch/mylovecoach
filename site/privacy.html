2. AI 분석을 위한 정보 전송

이용자가 코칭을 요청하면 해당 요청에 필요한 정보(대화 캡처 이미지, 상황 설명, 내/상대 프로필, 최근 코칭 맥락)가 암호화된 통신(HTTPS)으로 앱의 중계 서버를 거쳐 AI 처리 위탁사인 Google LLC의 Gemini API로 전송되어 답변 생성에 사용됩니다. 중계 서버는 요청을 저장하지 않고 즉시 전달만 합니다. 같은 방식으로 다음 기능도 AI 처리에 필요한 정보만 전송합니다: 상대 분석 보고서(상대·내 프로필, 기기에 저장된 코칭 요약과 호감 온도 변화), 연애 연습(선택한 연습 상대 설정, 내 프로필, 연습 중 주고받은 메시지), 속마음 풀이(선택하거나 입력한 상황 글, 내 성별·나이·MBTI). 이 세 기능의 내용은 이용 기록 수집 동의 여부와 관계없이 앱 운영자 쪽에 저장하지 않습니다. 전송된 데이터는 Google의 Gemini API 추가 서비스 약관 및 개인정보처리방침에 따라 처리됩니다.

이용자가 설정에서 개인 API 키를 등록한 경우, 요청은 중계 서버 없이 이용자 기기에서 해당 키의 제공사(Google Gemini API 또는 Anthropic API)로 직접 전송되며, 그 제공사의 약관과 개인정보 정책(Anthropic 개인정보 정책 등)이 적용됩니다.

3. 결제 정보

이용권(하루 이용권, 주간 구독, 평생권, 횟수권) 결제는 Apple App Store 또는 Google Play가 처리합니다. 앱은 카드번호, 계좌 등 결제수단 정보를 수집하거나 전달받지 않습니다. 앱은 이용권 적용 여부를 확인하기 위해 스토어가 기기에 제공하는 구매 내역(상품 ID, 거래 ID, 만료일)을 기기 안에서만 확인하며, 이를 앱 서버로 전송하거나 저장하지 않습니다. 하루 이용권과 횟수권은 결제한 기기에 충전되며, 같은 결제가 두 번 충전되지 않도록 거래 ID를 기기에 보관합니다. 다만 이용 기록 수집에 선택 동의한 경우, 이용 중인 프리미엄 종류(주간·평생)만 이용 기록에 포함됩니다.

4. (선택) 이용 기록 수집

이용자가 선택 동의한 경우에 한해, 서비스 개선을 위해 위 표의 「이용 기록」을 앱 운영자의 데이터베이스에 저장합니다. 동의하지 않아도 모든 기능을 그대로 이용할 수 있으며, 동의하지 않으면 어떤 이용 기록도 전송되지 않습니다.

  • 수집하지 않는 것: 업로드한 대화 캡처 이미지 자체는 저장하지 않고 첨부 여부만 기록합니다. 계정을 만들지 않으므로 이메일·전화번호·주소를 수집하지 않으며, 광고 식별자와 위치정보도 수집하지 않습니다.
  • 이용자 구분 방법: 앱이 기기에서 무작위로 만든 ID 로 구분합니다. 광고 식별자·전화번호·이메일은 쓰지 않으며, 이용 기록은 다른 회사와 공유하거나 광고에 쓰지 않습니다.
  • 동의 방법: 첫 화면의 「(선택) 이용 기록 수집」 체크박스를 이용자가 직접 체크하거나 마이 탭 스위치를 켠 경우에만 동의로 봅니다. 미리 체크된 상태로 받은 예전 동의로는 기록을 저장하지 않습니다.
  • 동의 철회: 앱의 「마이 → 이용 기록 수집」 스위치를 끄면 즉시 전송이 멈추고, 서버에 저장된 그 기기의 이용 기록도 바로 지웁니다. 이전 버전의 앱이거나 따로 요청하시려면 데이터 삭제 요청 방법으로 요청해 주세요. 7일 안에 지웁니다.
  • 보유 기간: 수집일로부터 1년이 지나면 매일 자동으로 파기하며, 동의 철회나 삭제 요청 시 지체 없이 파기합니다.
  • 처리 위탁: 데이터베이스 보관은 Supabase Inc. 에 위탁합니다.

대화 캡처에는 상대방의 이름, 메시지 등 제3자의 정보가 포함될 수 있습니다. 이용자는 해당 정보를 본인의 책임 하에 개인적인 조언을 얻기 위한 목적으로만 이용해야 하며, 앱은 이를 다른 목적으로 사용하거나 공개하지 않습니다.

6. 보유 및 파기

선택 동의한 이용 기록(4번, 1년 보관)을 제외한 모든 데이터는 이용자 기기에만 보관되며, 이용자가 앱 내에서 채팅방을 삭제하거나 "모든 데이터 삭제"를 실행하거나 앱을 삭제하면 즉시 파기됩니다. AI 처리 위탁사에 전송된 데이터는 위탁사의 보관 정책(요청 처리 후 제한된 기간 내 삭제)에 따릅니다.

7. 앱 권한

  • 사진 보관함: 대화 캡처와 상대 사진을 불러오기 위해 사용합니다. 선택한 이미지만 접근합니다.
  • 카메라(선택): 상대 프로필 사진 촬영에만 사용합니다.
  • 다른 앱 위에 표시(선택, Android): 「플로팅 버블」을 켠 경우에만 사용하며, 다른 앱 위에 앱 바로가기 버블을 띄웁니다. 버블은 화면 내용을 읽지 않고, 누르면 앱의 빠른 코칭 화면을 열 뿐입니다. 버블이 켜져 있는 동안 상태 알림이 표시되며, 마이 탭이나 알림에서 언제든 끌 수 있습니다.
  • 진동: 버튼·결과 표시 때 진동 효과에 사용하며, 마이 탭에서 끌 수 있습니다.
