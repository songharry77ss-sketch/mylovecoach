비밀 상담으로 나눈 대화·캡처·결과는 앱 기록에 저장하지 않고, 비밀 상담 화면을 나가면 즉시 지웁니다(앱이 강제로 종료되면 다음 실행 때, 만든 지 10분이 지난 파일부터 지움). 이용 기록 수집에 동의했더라도 비밀 상담의 대화·캡처·결과는 이용 기록으로 남기지 않으며, 비밀 상담을 이용했다는 사실과 화면 체류 시간만 남습니다. 다만 비밀 상담 중 AI 답변을 직접 신고하면, 신고한 답변은 2번 「AI 답변 신고」에 따라 저장됩니다(앱이 신고 전에 알려 드립니다).

웹에서는 회원가입을 선택적으로 이용할 수 있습니다. 회원가입 기능이 없는 기존 스토어 앱은 계속 비회원으로 이용할 수 있습니다. 회원가입을 지원하는 버전에서도 가입하지 않고 맛보기 코칭과 이용권 결제를 이용할 수 있고, 해당 웹·앱에서 제공하는 카카오·Apple·Google 로그인으로 가입하면 무료 코칭 보너스와 매일 무료 코칭을 받을 수 있습니다(5번). 앱은 전화번호·위치정보·광고식별자를 받지 않으며, 이메일은 회원가입 때 이용자가 제공에 동의한 경우(5번)와 문의 메일(위 표)로만 받습니다. 회원 정보·로그인 보안 감사로그(5번), 선택 동의한 이용 기록·AI 운영 진단(4번), 이용자가 직접 보낸 AI 답변 신고(2번), 팀원으로 등록된 기기의 명단과 문의 메일을 제외하면 앱 운영자 쪽에는 이용자 데이터를 저장하지 않습니다.

2. AI 분석을 위한 정보 전송과 국외 이전

이용자가 코칭을 요청하면 해당 요청에 필요한 정보(대화 캡처 이미지, 상황 설명, 내/상대 프로필, 최근 코칭 맥락과 같은 채팅방에서 이전에 요청한 답장 방식·주의사항)가 암호화된 통신(HTTPS)으로 앱의 중계 서버(Vercel Inc.의 서버에서 운영)를 거쳐 AI 처리 위탁사인 Google LLC의 Gemini API로 전송되어 답변 생성에 사용됩니다. 중계 서버는 AI 요청 본문을 전달한 뒤 보관하지 않습니다. 별도의 운영 진단과 이용 기록 수집에 동의한 경우의 코칭 기록은 4번에 따라 저장합니다. 같은 방식으로 다음 기능도 AI 처리에 필요한 정보만 전송합니다: 상대 분석 보고서(상대·내 프로필, 기기에 저장된 코칭 요약과 호감 온도 변화), 연애 연습(선택한 연습 상대 설정, 내 프로필, 연습 중 주고받은 메시지), 속마음 풀이(선택하거나 입력한 상황 글, 내 성별·나이·MBTI). 이 세 기능의 내용은 이용 기록 수집 동의 여부와 관계없이 앱 운영자 쪽에 저장하지 않습니다(이용자가 직접 신고한 답변은 아래 「AI 답변 신고」에 따라 저장). 전송된 데이터는 Google의 Gemini API 추가 서비스 약관 및 개인정보처리방침에 따라 처리됩니다.

코치 서버에 연결된 앱(스토어에서 받은 앱과 웹)에서는 설정에서 개인 API 키를 등록해도 쓰이지 않으며, 요청은 위와 같이 중계 서버를 거쳐 Google 로 전송됩니다. 코치 서버가 없는 빌드에서 개인 API 키를 등록한 경우에만 요청이 중계 서버 없이 이용자 기기에서 해당 키의 제공사(Google Gemini API 또는 Anthropic API)로 직접 전송되며, 그 제공사의 약관과 개인정보 정책(Anthropic 개인정보 정책 등)이 적용됩니다.

앱은 AI로 보내기 전에 받는 곳을 안내하고 동의를 받습니다(최신 앱·웹 — 그 전 버전 앱은 동의를 따로 묻지 않고 보내므로 최신 버전으로 업데이트해 주세요). 동의하지 않으면 AI 기능(답장 추천·상대 분석 보고서·연애 연습·속마음 풀이)을 쓸 수 없으며, 마이 → AI 분석 동의 스위치로 언제든 철회할 수 있습니다.

개인정보의 국외 이전 (「개인정보 보호법」 제28조의8) — 위 전송, 4번의 이용 기록 보관, 아래 「AI 답변 신고」 보관, 5번의 회원 로그인·회원 정보 보관, 팀원 명단 보관과 문의 메일 처리를 위해 아래와 같이 개인정보가 국외로 이전됩니다.

AI 답변 신고

AI가 만든 답변이 불쾌하거나 부적절하면 앱을 떠나지 않고 바로 신고할 수 있습니다(답장 카드의 깃발 버튼, 연애 연습 화면 위 깃발(상대의 가장 최근 말)·상대 말풍선 길게 누르기·코치 피드백 옆 깃발, 상대 분석 보고서·속마음 풀이 화면 아래의 신고, 마이 → AI 답변 신고하기). 신고는 이용 기록 수집 동의와 관계없이, 이용자가 「신고하기」를 누를 때만 전송됩니다.

  • 보내는 것: 신고한 AI 답변 내용(상대 이름 등 대화 일부가 들어 있을 수 있음. 속마음 풀이는 물어본 상황 글도 함께), 고른 사유와 직접 적은 메모, 기능 종류(답장 추천·상대 분석 보고서·연애 연습·속마음 풀이), 답변을 만든 AI(예: 중계 서버의 Google Gemini), 앱 버전·기기 종류(iOS·Android·웹)
  • 목적: 부적절한 AI 답변의 검토와 필터 개선
  • 보관: 앱 운영자의 데이터베이스(Supabase, 대한민국 서울 리전)에 저장하고, 신고일로부터 1년이 지나면 매일 자동으로 파기합니다. 비밀 상담 중에 신고한 답변도 이렇게 저장되며, 앱이 신고 전에 알려 드립니다.
  • 저장하지 않는 것: 기기 ID와 IP 주소는 신고와 함께 저장하지 않아 누가 보낸 신고인지 알 수 없습니다. 지나친 신고를 막기 위해서만 IP 주소를 바꾼 값(해시)을 서버 메모리에 잠시 두었다가 지웁니다.
  • 삭제 요청: 보낸 사람을 알 수 없으므로, 지우고 싶은 신고가 있으면 신고한 날짜와 내용을 아래 개인정보 보호책임자에게 알려 주세요. 확인되면 지체 없이 지웁니다.

3. 결제 정보

이용권(하루 이용권, 주간 구독, 평생권, 횟수권) 결제는 Apple App Store 또는 Google Play가 처리합니다. 앱은 카드번호, 계좌 등 결제수단 정보를 수집하거나 전달받지 않습니다. 앱은 이용권 적용 여부를 확인하기 위해 스토어가 기기에 제공하는 구매 내역(상품 ID, 거래 ID, 만료일)을 기기 안에서만 확인하며, 이를 앱 서버로 전송하거나 저장하지 않습니다. 하루 이용권과 횟수권은 결제한 기기에 충전되며, 같은 결제가 두 번 충전되지 않도록 거래 ID를 기기에 보관합니다. 다만 이용 기록 수집에 선택 동의한 경우, 이용 중인 프리미엄 종류(주간·평생)와 결제 화면 열람·결제 시도와 결과(상품 종류, 스토어 오류 문구)가 이용 기록에 포함됩니다. 카드번호 등 결제수단 정보는 포함되지 않습니다.

4. (선택) 이용 기록 수집

이용자가 선택 동의한 경우에 한해, 서비스 개선을 위해 위 표의 「이용 기록」을 앱 운영자의 데이터베이스에 저장합니다. 동의하지 않아도 모든 기능을 그대로 이용할 수 있으며, 동의하지 않으면 이 절의 선택 이용 기록을 앱에서 보내지 않습니다. 아래 AI 운영 진단과 5번의 로그인 보안 감사로그는 별도입니다.

  • 수집하지 않는 것: 업로드한 대화 캡처 이미지 자체는 저장하지 않고 첨부 여부만 기록합니다. 다만 캡처 대신 글로 입력하거나 붙여 넣은 대화(상대방 메시지 포함)는 코칭 요청 내용으로 저장됩니다. 전화번호·주소·광고 식별자·위치정보는 수집하지 않습니다.
  • 이용자 구분 방법: 앱이 기기에서 무작위로 만든 ID 로 구분합니다. 회원가입한 경우에는 이용 기록이 회원 정보와 연결됩니다. 광고 식별자·전화번호는 쓰지 않으며, 이용 기록은 다른 회사와 공유하거나 광고에 쓰지 않습니다.
  • 동의 방법: 첫 화면의 「(선택) 이용 기록 수집」 체크박스를 이용자가 직접 체크하거나 마이 탭 스위치를 켠 경우에만 동의로 봅니다. 미리 체크된 상태로 받은 예전 동의로는 기록을 저장하지 않습니다. 그 예전 동의로 이전 버전 앱·웹이 이미 보낸 기록은 아래 보유 기간이 지나면 파기하며, 그 전에라도 최신 앱의 「마이 → 예전에 보낸 이용 기록 지우기」나 데이터 삭제 요청으로 지울 수 있습니다.
  • 동의 철회: 앱의 「마이 → 이용 기록 수집」 스위치를 끄면 즉시 전송이 멈추고, 앱이 서버에 저장된 그 기기의 이용 기록 삭제를 요청합니다. 연결이 끊겨 있으면 다음에 앱을 켤 때 다시 요청하며, 끄기 직전에 보낸 코칭 요청이 늦게 저장된 기록까지 지웁니다. 삭제가 끝날 때까지는 다시 동의해도 새 기록을 보내지 않습니다. 「모든 데이터 삭제」를 실행해도 서버 기록 삭제를 요청하며, 이용 기록 동의도 처음 상태로 돌아가 첫 화면에서 다시 묻습니다(최신 앱·웹). 이전 버전의 앱이거나 따로 요청하시려면 데이터 삭제 요청 방법으로 요청해 주세요. 7일 안에 지웁니다.
  • 보유 기간: 화면·버튼·코칭 기록과 처음 들어온 경로는 수집일로부터 1년, 기기 ID·프로필·기기 종류 등 이용자 정보는 마지막 이용일로부터 1년이 지나면 매일 자동으로 파기하며, 동의 철회나 삭제 요청 시 지체 없이 파기합니다.
  • 처리 위탁과 국외 이전: 데이터베이스 보관은 Supabase Inc. 에 위탁하며, 이용 기록은 미국 회사인 Vercel Inc.(중계 서버)와 Supabase Inc.(보관, 서울 리전)가 처리합니다. 받는 곳·연락처·이전 시기와 방법·보유 기간은 2번 국외 이전 표에 있습니다.

AI 서버 운영 진단 (선택 이용 기록과 별도)

AI 요청을 처리할 때 기능 종류, 모델, 응답 상태·정해진 오류 코드, 토큰 수, 시도 수, 종료 이유, 캡처 첨부 여부와 처리 시간을 Vercel 실행 로그에 기록하여 비용·장애를 진단합니다. 이 구조화 진단 로그에는 대화 본문·사진 원본·이름·이메일·회원 ID·기기 ID·IP 주소를 넣지 않습니다. 다만 Vercel이 요청별로 관리하는 실행 로그이므로 완전히 익명인 집계라고 단정하지 않습니다. 이용 기록 스위치를 꺼도 AI 요청의 운영 진단은 기록됩니다.

현재 운영 요금제의 Runtime Logs 보관 기준은 1시간이며 외부 로그 저장 연동(Drains)은 사용하지 않습니다. 회원 탈퇴나 선택 이용 기록 삭제와 별개로 이 서비스 보관 기간을 따릅니다. 특정 회원의 기록을 찾아 지우는 용도로 회원·기기 식별자를 넣지는 않습니다. 이 기간은 Vercel의 모든 내부 보안 기록·백업까지 같은 시점에 파기된다는 뜻은 아닙니다.

5. (선택) 회원가입 — 웹 및 회원가입 지원 버전

  • 가입 방법: 카카오·Google로 로그인하며, Apple 로그인은 해당 기능을 지원하는 iOS 앱에서 제공합니다. 앱은 각 제공자의 비밀번호를 받지 않으며, 로그인 처리는 Supabase Inc.(인증 위탁)와 각 제공사가 합니다. Google 로그인은 회원 식별·이메일·기본 프로필에 해당하는 권한(openid, email, profile)만 요청합니다.
  • 받는 정보: 위 표의 「회원가입」 항목. 카카오는 이용자가 동의한 항목(닉네임, 프로필 사진, 이메일)만, Apple은 이름(처음 가입할 때 한 번)과 이메일(가리기 선택 가능)을 받습니다. Google은 회원 식별자, 이메일과 이메일 확인 상태, 제공되는 이름·프로필 사진 주소를 받습니다. 회원 정보에는 제공자·이름/닉네임·이메일을 기록하고, 회원 식별자와 제공되는 기본 프로필은 인증 서비스의 계정 정보에도 포함됩니다. 프로필 사진 주소는 이 인증 정보에 보관될 수 있지만 앱 화면에는 쓰지 않으며, 사진 파일을 별도로 저장하지 않습니다. 로그인한 기기마다 무작위 ID 와 로그인 시각을 보관해, 그 기기의 이용 기록(4번)을 회원과 잇고 탈퇴할 때 함께 지우는 데 씁니다.
  • 대화 내용: 가입해도 대화 캡처와 채팅방은 지금처럼 이용자 기기에만 저장됩니다. 다만 이용 기록 수집(4번)에 동의했다면 코칭 기록(상대 별명·나이·MBTI 같은 상대 정보, 입력한 상황 글, 코치 답변)이 서버에 저장되고 회원 정보와 연결됩니다. 캡처 이미지는 앱 운영자의 서버에 저장하지 않습니다. 이용자가 직접 신고한 AI 답변은 이용 기록 동의와 별개로 2번에 따라 저장됩니다.
  • 탈퇴: 회원가입을 지원하는 웹·앱의 「마이 → 회원 탈퇴」로 언제든 탈퇴할 수 있고, 탈퇴하면 회원 정보·로그인 계정과, 회원 계정에 연결된 기기의 이용 기록(4번)을 지체 없이 파기합니다. 다만 가입 보너스의 중복 지급을 막기 위해 보너스를 받은 기기의 무작위 ID 와 지급 시각만 탈퇴일로부터 1년간 보관한 뒤 파기합니다. 앱을 쓸 수 없으면 데이터 삭제 요청 방법으로 탈퇴를 요청할 수 있습니다.
  • 신고 내용 삭제: AI 답변 신고에는 회원·기기 식별자를 저장하지 않으므로 회원 탈퇴만으로 특정 신고를 찾아 삭제할 수 없습니다. 삭제를 원하면 2번에 따라 신고 날짜와 내용을 알려 주세요.
  • 구독 해지: 회원 탈퇴는 App Store·Google Play의 자동 갱신 구독을 해지하지 않습니다. 구독 중이라면 App Store 구독 관리 또는 Google Play 구독 관리에서 별도로 취소해 주세요. 가입하지 않고 구매한 구독도 같은 방법으로 관리할 수 있습니다.
  • 로그인 제공사와의 연결: 회원 탈퇴는 이 앱의 회원 정보와 로그인 계정을 삭제하는 기능이며, 카카오·Apple·Google 계정 자체를 삭제하지 않습니다. 로그인 제공사와의 연결은 회원 탈퇴와 별개입니다. Google은 Google 계정의 연결된 앱에서 「나만의 연애코치」의 Google 계정으로 로그인을 사용 중지하고, 카카오는 카카오 계정의 연결된 서비스 관리에서 해제해 주세요. 앱에서 탈퇴해도 이 연결이 자동으로 해제됐다고 가정하지 마세요. 반대로 제공사 연결만 해제해도 앱에 이미 저장된 회원 정보는 남으므로 회원 탈퇴도 함께 요청해 주세요.
  • Apple 연결 계정의 탈퇴: 자동 연결 해제를 완료하지 못하면 회원 정보를 먼저 지우지 않고 다시 시도할 수 있도록 안내합니다. 또는 Apple의 수동 연결 해제 방법을 확인한 뒤, 자동 연결 해제가 완료되지 않았음을 이해하고 별도 최종 확인으로 앱 회원 삭제를 요청할 수 있습니다. 이 경우 회원 삭제 완료와 Apple 연결 해제 완료는 구분하며, Apple 설정에서의 연결 관리는 이용자가 따로 해야 합니다.
  • 로그인 보안 감사로그: 로그인 처리 위탁사(Supabase)가 계정 보안을 위해 로그인 시각, 회원 식별자, IP 주소와 인증 이벤트를 회원 정보와 별도의 로그에 기록합니다. 이 로그는 회원 탈퇴 시 즉시 삭제되는 회원 정보에 포함되지 않으며, 현재 이용 중인 요금제의 Auth Audit Logs 보관 기준(1시간)에 따라 보관됩니다. 운영 데이터베이스에 감사로그를 별도로 저장하는 기능은 사용하지 않습니다.
  • 회원 정보 보유 기간: 탈퇴할 때까지 보관합니다. 로그인 보안 감사로그와 가입 보너스 중복 지급 방지 정보는 각각 위에 안내한 별도의 기간을 따릅니다. 1년 이상 로그인하지 않으면 미리 알리고 회원 정보를 파기할 수 있습니다.

대화 캡처에는 상대방의 이름, 메시지 등 제3자의 정보가 포함될 수 있습니다. 이용자는 해당 정보를 본인의 책임 하에 개인적인 조언을 얻기 위한 목적으로만 이용해야 하며, 앱은 이를 답변 생성, 이용 기록 수집에 동의한 경우의 서비스 개선(4번), 이용자가 신고한 AI 답변의 검토(2번) 외의 목적으로 사용하거나 공개하지 않습니다.

7. 보유 및 파기

회원 정보·로그인 보안 감사로그(5번), 선택 동의한 이용 기록·AI 운영 진단(4번), AI 답변 신고(2번, 신고일로부터 1년 보관), 팀원 명단·문의 메일(1번 표)을 제외한 앱 기록은 이용자 기기에 보관됩니다. 채팅방을 삭제하면 해당 채팅방과 분석 재사용 사본을 지우고, "모든 데이터 삭제"를 실행하면 기기의 프로필·채팅방·캡처·연습·속마음 기록과 재사용 사본을 함께 지웁니다. 다만 무료 코칭 사용 횟수·이용권과 중복 충전 방지용 거래 ID, 기기 ID, 처음 들어온 경로, 회원 로그인 상태는 기기에 남습니다(구매한 이용권을 지키고 무료 횟수가 다시 생기지 않게 하기 위함). AI 분석 동의와 이용 기록 동의는 처음 상태로 돌아가 다시 묻습니다. 앱을 삭제하면 기기 내 앱 기록이 함께 지워지며, 웹에서는 브라우저의 사이트 데이터 삭제를 이용할 수 있습니다. AI 처리 위탁사 등 국외로 이전된 데이터의 보관과 이용은 2번 표와 각 회사의 약관·개인정보 정책에 따릅니다.
